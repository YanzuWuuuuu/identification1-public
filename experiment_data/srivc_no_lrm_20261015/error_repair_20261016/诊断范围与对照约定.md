# 逐通道误差诊断与修复范围

用户目标：给出全部16路误差曲线，解释上一轮通道时延改善有限的原因并修复。

基线：2026-10-16 的输入/输出加性7时延 SRIVC，z=0 mm，25–800 Hz。固定训练/验证划分及训练 LRM，固定二次目标权 W=1/max(|Htrain|,epsilon)，不用逆平方权。

对照边界：已多次观察这份后半段验证记录，本轮属于开发期探索验证，不把它重新称为未见的最终测试集。所有方案保留同一参考、频点和误差定义；分别报告 Welch、LRM，不把二者数字混用。

运行环境：本机 MATLAB R2025a，Intel i5-12600KF、10个物理核、约32 GiB内存。1550×16复FRF及约20–24个共享分母坐标可以本机完成；一次只运行一项MATLAB拟合。无需额外硬件或外部计算。

有限诊断顺序：

1. 已完成：全部通道幅值误差、主值相位误差、复残差；训练/验证FRF差仅作为重复性参考。
2. 已完成：冻结7时延和高阶极点，仅profile原来固定的带外背景频率、阻尼，检验低频误差是否由错误固定参数造成；随后运行真正SRIVC放开原结构全部共享极点。
3. 已完成：从修正背景的结果出发，重新优化7个输入/输出加性时延，内层仍为SRIVC。记录失败候选及收敛门槛，不把未收敛点当作profile驻点。
4. 已完成：依据相邻124/128Hz特征、重复772Hz小峰、弱交叉通道低频尾部和180–320Hz宽残差分别开展结构对照；新增结构单独记录，不能解释成仅时延的收益。

最终结果：Welch全带误差17.0547%→8.0152%，LRM 15.1317%→3.4837%；两个重点凹口中心和外侧均改善。两个自由带外背景的未收敛候选没有采用。完整结果见《逐通道误差诊断与修复报告.md》。本轮停止结构扩张，后续转独立验证和物理归属核查。

停止条件：主要误差来源有隔离对照证据，修复在原指标下产生可复现改善，16路误差图和剩余问题已保存。不要求无限加阶使每个噪声尖峰重合。

本轮不修改论文正文、原始实验数据或 matlab/1–4。主证据为已有模型错误的诊断及修复；硬件绝对时延、零空间校准工程验证不由本次结果认证。
