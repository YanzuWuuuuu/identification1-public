# 完整逻辑轴与零空间校准：数学和公平评价审查

日期：2026-10-16。本文是本轮实现的独立数学检查，不代表新增实测收益。仅检查离线矩阵变换，不接入实际控制器。旧的原始数据、辨识结果和评价文件保持不变。

## 1. 矩阵更新成立，但应准确限定“保持标定”

设估计的共同支撑项为 C F(s) B，C∈R^(4×3)、B∈R^(3×4) 满秩；ny、nu 为其左右单位零向量。固定原几何逻辑矩阵 P0∈R^(3×4)、Q0∈R^(4×3)。目标模态的实空间近似写成 c g(s) bᵀ。定义 ay=nyᵀc、au=bᵀnu。

当 ay、au 非零时：

P1=P0−(P0c/ay)nyᵀ，Q1=Q0−nu(bᵀQ0/au)。

应逐项数值检查：

- P1 C=P0 C，B Q1=B Q0。
- P1 c=0，bᵀQ1=0。
- nyᵀC=0，Bnu=0。

不要求 P0C 或 BQ0 为单位阵。它们是固定的映射，不能在每个候选下再归一化。这些等式保持的是**估计支撑空间上的原映射**；C、B 尚未获得真实物理标定时，不能把这些等式解读为真实位姿标定已经被证明准确。另行报告 P1C_nom−P0C_nom 与 B_nomQ1−B_nomQ0，可揭示相对于原几何模型的变化，不以该差值为零作为新模型正确的必要条件。

## 2. 对一般复留数，不能只取实部的 SVD

对上半平面物理极点 p，目标模态写成

Gf(s)=R/(s−p)+conj(R)/(s−conj(p))。

最佳单个实方向对近似定义为

min_(||c||=||b||=1, c,b real, α complex) ||R−αcbᵀ||_F²。

对固定 c,b，有 α=cᵀRb。因此等价于最大化 |cᵀRb|，又等价于

max_(φ∈[0,π]) σmax(Re(exp(−iφ)R))。

对每个 φ 的实矩阵做 SVD，取左右首奇异向量；以最优 φ 对应 c,b 和 α=cᵀRb 构造 Rhat。密集网格加各局部峰细化可可靠数值求解，但若无界证书，不称为严格全局已认证。网格最大间距为 h 时，最大奇异值函数的 Lipschitz 上界给出网格最优距真最优至多 ||R||₂ h/2；可把此界作为计算精度报告。

若现有模型使用 q=s/(2πfref)、A(q)=1+a1 q+a2 q² 与实分子 C0+qC1，则 q_p 为 A 的上半平面根，物理留数应为

R=2πfref (C0+q_p C1)/(a1+2a2 q_p)。

报告以下不同诊断，不把它们混为一谈：

- 复秩一误差：sqrt(sum(σ₂:end²))/||R||_F。
- 实方向对误差：ε_R=||R−αcbᵀ||_F/||R||_F。
- 真实空间需求：svd([Re R, Im R]) 及 svd([Re Rᵀ, Im Rᵀ])。
- ηy=|nyᵀc|、ηu=|bᵀnu|（四个向量均单位化）。

复秩一并不意味着可由一个实方向描述。复杂模态的实、虚部可能需要两个实维度，而四通道减去三维支撑只有一维冗余。

## 3. 留数近似误差如何进入解耦误差

令 E_R=R−Rhat，Ef(s)=E_R/(s−p)+conj(E_R)/(s−conj(p))。有

||Ef(s)||₂ ≤ ||E_R||₂ (1/|s−p|+1/|s−conj(p)|)。

完整更新后，目标模态的两个非理想交叉块分别为 P1 Ef(s)nu 与 nyᵀ Ef(s)Q1。故其上界分别为

||P1||₂ ||Ef(s)||₂ ||nu||₂，
||ny||₂ ||Ef(s)||₂ ||Q1||₂。

因此留数近似误差即使看起来不大，也会被过大的坐标增益放大。应同时显示真实复留数变换后的目标交叉残留，不能只画被强制实秩一化的目标项（后者为零是代数事实）。总实测 FRF 的交叉块还包含其他模态、残余动态、通道动态误差和测量误差。

## 4. 公平评价约定：允许矩阵改变，不允许偷偷缩放赢

1. 保存并输出物理几何 P0、Q0 以及 P1、Q1。所有候选使用同一个固定尺度。若为汇总 Rx/Ry/Z 三个不同量纲的轴而使用单位方向尺度，应只计算一次 Dy=diag(1/rownorm(P0))、Du=diag(1/colnorm(Q0))，所有候选比较 Dy Pj 与 Qj Du。不可对 P1、Q1 每行/列重新单位化。
2. ny、nu 的方向和单位尺度在“仅零空间更新”和“完整坐标更新”间完全一致。纯相对时延对齐也相同，才能将改进归因于 P/Q 更新。
3. 在上述条件下，两方法的 N→N 对**任意**实测 H 严格相同，因为第四行、第四列未改；这是实现检查，不是目标模态辨识正确或独立实测保留率的证据。
4. 以固定逻辑命令幅值比较串扰，同时报告每轴电机指令范数 ||Qj(:,a)||₂/||Q0(:,a)||₂。改变 Q 后消耗的物理命令会不同，应报告而非再次缩放掩盖。
5. 以固定逻辑标定比较输出串扰，同时报告 ||Pj(a,:)||₂/||P0(a,:)||₂。这只是白色等方差独立传感噪声的幅值增益；实际噪声协方差未知，不能声称实际噪声已测得或保持不变。若有 Σy，则比较 diag(PjΣyPjᵀ)。
6. 目标频段、低频支撑段、其余频带均报告。只降低目标峰值不代表整段控制串扰降低；应报告目标频带总复 FRF 残差而非只画模型被消掉的一阶模态。
7. 所有方向、候选选择、阈值从训练数据或预先声明获得。后半段已经多轮用于诊断，只能称冻结后的分段检查，不能重命名为新独立验证实验。

## 5. 防止共同支撑 rank=3 的循环证明

结构模型的 C 为 4×3、B 为 3×4，当然会有零空间；此事实只检验代码，不能证明实测支撑确实三维。必须从未施加该结构的模型提取低频留数，形成

Y=[Re R1, Im R1, …, Re Rm, Im Rm]，
U=[Re R1ᵀ, Im R1ᵀ, …, Re Rmᵀ, Im Rmᵀ]。

报告 σ4/σ3、σ3/σ1、第四奇异值能量占比，以及未约束自由估计的左右最小奇异向量与结构零向量夹角。原始留数堆叠与每模态统一幅值后的结果可同时报告，说明尺度选择；不选让结果最好看的尺度作为唯一证据。

进一步有价值的检查是固定极点，分别从前、后半段重新估计自由分子，比较子空间角度及支撑频响的预测误差。这仍是同一记录的分段敏感性检查，没有独立外部激励时不能赋予一致性或正确物理归属保证。不能把 100–150 Hz 模态自动计入三维支撑，也不能以全频 FRF 第四奇异值很小替代模态空间检验。

## 6. 有界增量可作为诊断，但不能事后挑选

若全量更新增益过大，可预先定义 Pγ=P0−γy(P0c/ay)nyᵀ、Qγ=Q0−γu nu(bᵀQ0/au)，0≤γy,γu≤1。支撑映射仍保持，理想目标交叉块分别按 1−γy、1−γu 缩减，NN 不变。γ 只能由预先设定的噪声/驱动增益上限或训练目标选取，不能看分段检查结果再选。

例如 pγ=p0−γβnyᵀ 的白噪声方差比例必须用真实范数计算：||pγ||²=||p0||²−2γβ p0ny+γ²β²。因估计 ny 不必正交于名义 p0，不能省略交叉项。同理处理输入列。

## 7. 本轮应具有的实现断言

- 模型响应/模态残差与保存模型一致；向量化采用输出索引最快。
- 支撑映射保持、实秩一目标抵消达到浮点精度。
- 更新前后 NN 整个复频响相同（相同 ny/nu 和动态补偿下）。
- 独立计算 transformed full FRF 与分块公式相符。
- 矩阵全部有限、实数、满秩；归一化固定；增益如实报告。
- 从复留数到实方向近似后的误差单独保留，不被强制结构抹掉。
- 结论仅为已有 FRF 下的离线可行性；实际闭环仍需已知 K 和新的运行验证。

## 10. 新恢复参考下的矩条件提醒

若每个频率仅有一个重复的激励向量 D_k，则

||(Y_k−G_θU_k)D_kᴴ||_F²=||D_k||² ||Y_k−G_θU_k||²。

仅逐频右乘参考再平方求和，仍是加权输出误差，不能自动获得闭环 IV 的去偏性质。真正的 IV/GMM 应先形成具有足够独立信息和有效聚合的工具矩条件，或从外部参考驱动的局部回归估计 G_ud、G_yd，再处理其矩方程和不确定度。跨独立重复周期构造回归/工具是另一种候选，但应在训练周期内部交叉拟合，不能用后半段构造工具后继续称其未参与估计。

## 11. 恢复参考辨识脚本初版审查

已审查 `run_recovered_reference_identification.m`。它确实先用 91 个相邻 DFT 点聚合估计 d→[U;Y] 的局部有理模型，再做固定极点、时延的自由分子回归；没有使用第 10 节指出的单频伪 IV 目标。

归一化与索引核查通过：H 的维数为频率×输出×参考；物理 FRF 为 `(Tyd/Tud)*ys./us`，按输入列恢复单位。矩拟合 X 的行按四个参考分块，与 `reshape(Tyd(:,y,:),[],1)` 一致；估计归一化系数乘 ys/us(u) 恢复物理系数。原输出尺度 ys 为公共标量。第四电机恰好等于恢复外激励，因此其 T_ud 行可以使用已知直接项 ds(4)/us(4)。

初版发现的审查事项已反馈主实现者：

1. 局部回归应检查秩、参数有限性；矩回归应检查列尺度非零且有限。不能只记录条件数而忽视实际失秩。
2. 旧 direct LRM 的 25–800 Hz 使用截断后的原频率网格，新脚本初版使用全网格。因此靠近 25/800 Hz 的邻域不同。若要严格归因于参考入口，应统一窗口；否则在报告中说明端点比较混杂。
3. 高频 U≈D 时，直接拟合 U 的 LRM 分母列 −xU 与分子 xD 近共线。条件恶劣时应估计 ΔU=U−D 的参考传函再加已知直接项，或用已知分配矩阵将逻辑反馈传函映射回总 U；不以任意放宽秩阈值掩盖。
4. 该实现是参考驱动 LRM 加局部传函矩拟合，尚不是标准闭环 SRIVC 的完整实现。分母回归使用含噪输出，有限邻域近似、传函矩估计和冻结的数据权重均有统计边界；不能宣称有限样本严格无偏或已经验证渐近正态。
5. 直接/reference FRF 两个拟合共用旧固定权重，适合检查入口差异。额外矩拟合使用另一种权重与目标，应单独列出，不能将其收益全部归因为 IV。其权重含估计 T_ud，只是本轮固定，不能被描述为事前确定的非随机权重。

这一检查没有使用 MATLAB 共享会话，也没有更改被审查脚本；最终状态以主实现者应用修正后的源文件和实际运行证据为准。

## 12. 新版参考入口与结果复核

主实现者已按实际反馈分配修改为先估计 d→V_logic 和 d→Y，再构造

T_ud=diag(ds./us)+diag(1./us) Q_alloc diag(vs) T_vd。

再次检查归一化正确，已知直接项自然保留，局部窗口与旧方法统一，局部秩与参数有限性门槛已补。使用记录的反馈控制量并不需要猜测实际控制器 K，但不等价于已获得部署新校准器后闭环稳定性的证明。

新版落盘 CSV 在 25–800 Hz 给出同自由分子参数量比较：

| 模型 | 后半段参考响应相对误差 | 后半段原入口 FRF 相对误差 |
|---|---:|---:|
| 原入口 FRF，同极点/时延自由分子 | 5.34348% | 5.48177% |
| 参考入口 FRF，同原权重 | 4.76697% | 4.88754% |
| 参考传函矩目标，新冻结权重 | 3.36214% | 3.66464% |

前两行支持固定权重下入口变化带来约 10.8% 的相对误差下降。第三行同时改变估计目标和权重，其额外收益不能全部归因于消除了闭环偏差；可准确称为“参考入口与响应矩目标组合的离线改善”。

在归一化坐标下，若 G_ref=T_yd/T_ud，则矩残差为 (G_ref−G)T_ud。输出权重为 Wy 时，对应 FRF 残差的隐含输入权重是 T_ud T_udᴴ：

||Wy^(1/2)(G_ref−G)T_ud||_F²。

因此反馈压低的输入方向可能在该目标中权重较小。参考响应预测改善，不自动保证弱方向的开环 G、低频支撑空间或零向量准确。3–25 Hz 的参考重构与旧 FRF 差别很大，T_ud 条件数最大约 70.5；现有数据不足以直接宣称其中某一个前端就是真值。新零空间的提取需先检查自由低留数的第四奇异值和分段敏感性，并在两种前端下共同评价。

## 13. 新参考零空间与完整坐标评价复核

只读检查了 `evaluate_recovered_reference_calibration.m` 与对应 gains/metrics CSV。以下实现正确：

- 前三低频模式使用相同冻结极点，提取实/虚留数堆叠后做 SVD；取前三维空间与第四向量。该步骤明示是领先三维投影，未将全部自由留数强制清零。
- 原逻辑矩阵 P/Q 及固定恢复尺度取自上一轮结果；新候选未重新按行/列单位化。
- 两套 FRF 都保持原单位，并施加同一旧模型相对延迟；新旧 N 的对照无频率或通道索引错位。
- 增量只由训练矩目标系数生成；后半段重估只用于敏感性，不参与方向或增量比例的选择。
- 增益限制同时检查每行/列、逻辑算子及完整算子。完整算子限制的基准是同一 R1 的新 N，无基准切换。
- NN 不变断言正确比较 R1、R2、R3，即同一 N 下的完整逻辑方向更新。

发现的命名问题已由主实现者修复并在源码中核实：`fixed_physical_*_basis_preserved` 已改为 `estimated_support_*_basis_preserved`。这些断言只针对估计的前三维支撑基，绝不能表述为真实物理轴标定已经校准。

数值复核：

- R1 在 25–80 Hz 的逻辑→N，相对旧 B4 分别为 1.28635（旧前端）和 1.27296（参考前端），未改善。
- R2 完整输入命令列增益最大 83.7002 倍，完整输入算子约 78.2319 倍；260–310 Hz 的逻辑→N 相对旧 B4 仍为 1.02559/1.02786，并没有目标带收益。
- R3 限增益后该目标带比值约 0.99723，只有约 0.28% 变化；25–80 Hz 则为 1.32211/1.30650。
- **重新估计 N 本身改变了目标响应。**260–310 Hz 的 N→N RMS，R1/R2/R3 相对旧 B4 只有 0.46845/0.46874。虽然 R1→R2/R3 的 NN 保持恒等，但不能据此笼统宣称“新方法保留了旧目标柔性响应”。新 N 的方向变化已使这一频带响应约减半，且不是坐标重标度造成。

### 不能将当前病态估计等同硬件不可解耦

主运行返回的新输入投影约 0.0119，输入 N 在两半记录的条件重估间变化约 1.61°。两单位方向的距离为 2sin(1.61°/2)≈0.0281，已大于名义投影 0.0119。由 |bᵀδnu|≤||δnu|| 可知，目前方向敏感性的量级足以覆盖这个小分母。
