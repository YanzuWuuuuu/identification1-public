# 低频弹簧纳入辨识与百赫兹模态核查

日期：2026-10-16。对象：`auto_identify_motor1234_z0.mat`，z=0 mm。本轮只新增辨识结果和诊断图，未修改原始记录、旧辨识结果、论文或 `matlab/0–4`。

## 结论

**可以把弹簧频段一并纳入 SRIVC，但目前得到的是有明显改善、仍有低频残差的联合模型。** 不能把“漏建弹簧”当作全部误差的唯一原因，也不能把本轮全部拟合极点当成已确认的机械模态。

最终三个低频分量的固有频率约为 **10.674、12.310、16.106 Hz**。相对同一次记录后半段的 LRM 复频响，3–25 Hz 误差由旧模型外推的 **188.79%** 降至 **40.44%**；25–800 Hz 由 **3.48%** 变为 **5.08%**。因此旧的高频专用模型仍保留，新模型不能被描述为所有频段都更优。

**124.59、128.22、137.77 Hz 暂不能归为板自身模态。** 原 4×4 仿真与参考自由板有限元均未预测这些频率，空间响应也未与原五阶参考振型形成明确对应。约 281.24 Hz 分量与原第一板模态的对应证据则明显更强。

## 1. 数据入口和可比性

- 采样率约 5000 Hz，去掉初始 1 s，再取前、后各 30 s。前半段训练，后半段做探索性验证。后半段已多次参与开发分析，不是保留至最后的独立测试集。
- 输入仍为四路闭环总电机指令，输出为四路 `pre_y`。原始 `d_z/d_Rx/d_Ry` 全为零，不能作为外部工具变量。未增加未知控制器模型或闭环噪声模型，不能声称这批 FRF 或参数无偏。
- 旧模型只拟合 25–800 Hz，含两个固定的带外有理背景分量；它们不是通过低频数据辨识出的弹簧模态。本轮以三个自由低频极点替代这两个背景分量。
- 新拟合范围为 3–800 Hz。0.5–3 Hz 只作数据质量检查，不作为本轮拟合结果。
- 25 Hz 以上严格复用上一轮相同的训练/验证 LRM 数组；其实际旧网格为约25.5–800 Hz，旧采样率浮点取值导致名义25 Hz点未被选入，本轮没有偷偷补进该点改变对照。低频从原始复 DFT 重算 LRM。局部有理模型采用二阶分子/边界多项式和二阶公共于各输入的分母，每个输出单独估计，最终采用半窗45条 DFT 线，窗口总跨度约3 Hz。
- 低频网格0.1 Hz，上频网格0.5 Hz；目标函数包含频率步长，防止密采样低频被额外重复加权。幅值单位仍为“记录输出/电机指令单位”，不擅自换成 m/N。

## 2. 模型、SRIVC 与权函数

各通道仍使用加性二阶模型和可分离输入/输出时延：

\[
\widehat G_{jk}(s)=e^{-s\ell_{jk}}\left[D_{jk}+
\sum_{m=1}^{n_m}\frac{b_{0,mjk}+b_{1,mjk}q_m}{1+a_{1m}q_m+a_{2m}q_m^2}\right],
\quad q_m=\frac{s}{2\pi f_{\mathrm{ref},m}},\qquad
\ell_{jk}=t_0+\Delta t^y_j+\Delta t^u_k.
\]

令第一路输入、输出相对时延为零，共7个规范化时延坐标。没有退回“所有通道同一个时延”。模型具有15个二阶有理分量，其中3个在25 Hz以下；15个分量不等于15个已确认的机械模态，宽带残差分量及其余附加极点仍需物理核查。模态留数未施加秩一约束。

内层继续使用 `frf_srivc_fit` 的实部/虚部堆叠工具变量迭代及 Schur 消元，所有低频和高频分母均自由估计；外层对7个时延坐标做 profile 优化。最终内层 score=6.39e-7，外层梯度无穷范数=3.59e-8，外层正常结束。它们证明本次求解满足采用的数值停止条件，不证明全局最优或物理时延唯一。

保留用户要求的**幅值倒数权，不使用幅值平方倒数权**：

\[
J=\sum_k\Delta f_k\,\beta(f_k)\sum_{j,u}
\frac{|H^{\rm train}_{ju}(f_k)-\widehat G_{ju}(f_k)|^2}
{\max(|H^{\rm train}_{ju}(f_k)|,\epsilon_{ju})},
\qquad
\epsilon_{ju}=\max\left(10^{-3}\max_{25\le f<800}|H^{\rm train}_{ju}(f)|,\operatorname{eps}\right).
\]

正则下限沿用旧上频段训练数据定义，不因加入幅值更大的低频峰而扩大凹口正则。只增加明确记录的频段系数：最终 \(\beta=0.03\)（3–25 Hz），其余为1。全局归一化常数不影响最优解。

为什么需要频段系数：不分频段时，3–25 Hz 虽只占约22 Hz，却占加权数据能量约83.34%。直接联合优化会牺牲原上频段拟合。比较的系数为1、0.3、0.1、0.03、0.01、0.003；选取**满足上频段加权训练误差不超过旧值1.10倍的最大系数**。这个门槛在扫描前写入程序，选择不使用验证误差。最终上频段加权训练误差8.351%，低于门槛8.638%。这是明确的工程折中，不是统计最优权重定理。

## 3. 候选检查与最终效果

同一后半段参考上的复误差定义为 \(100\|\widehat G-H\|_F/\|H\|_F\)，不是幅值曲线的差，也不是拟合准确率。

| 参考与频带 | 旧25 Hz以上模型 | 新联合模型 |
|---|---:|---:|
| LRM，3–25 Hz | 188.79%（外推） | 40.44% |
| LRM，25–800 Hz | 3.48% | 5.08% |
| LRM，200–800 Hz | 4.77% | 4.80% |
| Welch，3–25 Hz | 171.36%（外推） | 63.64% |
| Welch，25–800 Hz | 8.02% | 8.93% |

两种非参数参考均显示低频改善，但低频参考之间的差别不可忽略。11 Hz附近尤其仍有明显幅相残差；约16 Hz附近的拟合和分半参数重复性更好。

已完成以下有界对照，结果全部保留：

1. 两个低频分量未通过内层 score 门槛；三个低频分量从四组不同初值收敛到同一分支。
2. 不分频段的三分量模型：低频验证38.90%，上频12.27%。不能只报告它的低频收益。
3. 再加第四个低频分量：低频验证约39.03%，几乎没有改善，未选用。
4. LRM半窗15、30、45对应低频两段FRF相对差异约81.68%、28.07%、19.11%；窄窗数值波动较大。半窗30重新拟合也未改善结果。窗口与模型选择均属于探索性开发，不构成独立泛化检验。
5. Welch低频目标的补充拟合未通过 score 门槛，保留为失败检查，不作为最终模型。Welch原频点仍用作额外参考。
6. 最终时延重新优化后，原反共振中心±5 Hz复误差：u1→y1由28.08%降至25.20%，u2→y2由27.79%降至25.16%；整个180–260 Hz窗口分别由15.83%变为17.72%、4.77%变为5.67%。中心与外侧的表现有折中，不能宣称全部凹口区域都改善。

## 4. 一百多Hz是不是板自身模态

### 模型来源核查

- 真正的原4×4平台在 `matlab/0/Multiple_main_Control.m`，三个双积分刚体坐标，五阶柔性频率286.43、344.58、488.27、705.67、738.83 Hz。
- 参考自由板有限元 `matlab/anlaysis/FEA_CB_ROM.m` 没有设置支承弹簧；已有独立复算的前三阶弹性频率为303.919、360.332、557.069 Hz。Craig–Bampton中的固定接口子问题不是实机固定边界。
- `Function_TURE_sys.m` 的150 Hz属于另一套SISO示例，不是本次4×4板模态，不能拿来为124–138 Hz作对应。
- 当前自由板配置不同于实机装配，也不同于作为主模型的 `matlab/0` 版本。因此模型未预测某峰，不等于实际装配绝不可能产生该峰。

### 空间响应核查

由实测四路 `pre_y` 对三路 `y_0__k_` 回归，恢复的记录映射约为

\[
L=\begin{bmatrix}
0.25&0.25&0.25&0.25\\
1.3812&1.3812&-1.3812&-1.3812\\
2.5707&-2.5707&-2.5707&2.5707
\end{bmatrix}.
\]

前半段拟合后预测后半段的相对残差约1e-14量级，说明这些记录确为四传感器的静态线性组合。该记录映射的零空间与设计矩形的 \(n=[1,-1,1,-1]^T/2\) 一致；它仍不是独立测得的真实刚体几何标定。

对去时延有理模型的复留数 \(R_m\)，计算非刚体幅值比例 \(\|n^T R_m\|_F/\|R_m\|_F\)。这不是能量比例。

| 候选频率/Hz | 名义非刚体幅值比例 | 与原五阶C2振型的最大MAC |
|---:|---:|---:|
| 10.674 | 3.42% | 0.944，原第三参考振型 |
| 12.310 | 5.88% | 0.552，原第二参考振型 |
| 16.106 | 2.26% | 0.033 |
| 124.588 | 21.89% | 0.284 |
| 128.224 | 9.43% | 0.068 |
| 137.769 | 27.89% | 0.195 |
| 281.24 | 97.46% | 0.957，原第一参考振型 |

这些结果支持：十几Hz响应主要与平台整体运动相容，结合已知重力补偿弹簧背景，可作为弹簧/支撑相关候选；281Hz同时具有接近原286.43Hz的频率和较高的第一参考振型匹配，候选对应较强。124–138Hz的原模型振型匹配较弱，加入弹簧后仍存在，不宜简单归为“低频漏模态造成的假峰”，也不能直接称为原板的前三阶弹性模态。

高MAC不能单独确定归属：10.674Hz分量与原第三参考振型的MAC也达到0.944，但其频率和整体运动特征并不支持将它指认为原488.27Hz板模态。这一反例说明，四点空间采样对不同物理模态可能产生相似的观测向量。

合理的暂定表述是：**当前实测输入输出频响中的附加动态特征，物理来源尚未完成归属。** 支撑、附件、执行器安装结构和测量/控制链都是待区分的来源，也尚未排除闭环估计偏差或模型近似产生的分量。这里只凭现有记录不能在它们之间作唯一选择。

四传感器只有一个非刚体观测方向；某柔性模态在这四点上也可能表现得近似刚体。MAC还依赖通道顺序、增益、相位及参考模型准确性。任何一个投影数或MAC数都不能单独证明物理来源。
