## 机械机制解释

一块近似刚性的板也能出现多组装配模态。最简例子是平台质量M经k1连接到支承质量m，支承质量经k2连接地基。其自由振动满足

Mm*omega^4 - [k1*m + M*(k1+k2)]*omega^2 + k1*k2 = 0。

这个两自由度系统可以有低、高两个频段的模态，完全不要求板本体弯曲。推广到倾转及多个连接点，补偿器杆件、端座、导向结构或弹簧自身分布质量都可能提供附加自由度。该例仅用于解释可能性，没有用未知质量/刚度反算实机，也没有声称它就是实物构型。

仅有无质量线性弹簧和z/Rx/Ry三个自由度的刚板模型最多给出三组振动模态。十几Hz的三组不能在这个模型中自动再生出三个百赫兹模态；若后者是机械来源，就需要额外自由度。真实六自由度台体中未纳入旧模型的横向或偏航约束运动，也是安装链候选之一。

补偿组件与连接支承是候选之一，理由是三组特征对工作点明显敏感；此特征尚不足以唯一定位来源。理想线性弹簧仅改变预压并不改变切线刚度；若将升频归因于补偿器，须有几何刚度、接触、有效圈数、端座约束或侧向变形改变等证据。不能直接写“压得更多所以更硬”。预应力影响模态的机制可参照COMSOL官方示例，但不能用其替代本机证据：
https://doc.comsol.com/6.4/doc/com.comsol.help.models.sme.bracket_eigenfrequency/bracket_eigenfrequency.html

测量参考端仍需核对。用户已确认探头安装在运动板，因此不能再假定探头位于独立固定支架。如果靶面在基座，四点相对位移包含板与基座两端的运动；若靶面另有独立安装，也需检查该安装的动态。一个不受工作点影响的独立结构自身频率应基本不随z改变，要解释当前频移仍需耦合、受力或工况变化。

## 估计伪特征与辅助检查

纯时延的模为1，不能单独产生幅值窄峰；一个普通一阶低通也不能单独生成这三组窄带共振。实际驱动内环、滤波器结构未知，因此还不能整体排除驱动链动态。

总电机指令是当前输入。理想无噪声且边界正确时Y=GU，反馈不会直接向这个G新增闭环极点。闭环输入与噪声相关时，谱估计会出现 S_yu*S_uu^(-1)=G+S_vu*S_uu^(-1) 的偏差。当前外部激励记录d为零，尚不能以外部参考消除这个解释。参考：Abdalmoaty与Smith，Small Noise Analysis of Non-Parametric Closed-Loop Identification (2024)，https://arxiv.org/html/2403.15771v2。

复查旧Welch缓存：z0的2s窗参考在百赫兹段也有相关峰谷，128.5/137.5Hz的局部峰可见。110–160Hz归一化输入谱条件数中位11.8、最大61.8。4s窗虽然相干性很高，条件数中位却达2596、最大1.25e5，幅值明显波动，不能把其更尖的峰当作更准确的物理证据。两个参考来自同一闭环记录，不是独立实验。局部频响幅值峰受背景和近邻模态影响，不能直接等同固有频率。

### 为什么三根弹簧不能直接等同于三个百赫兹模态

令刚板竖向及倾转坐标q=[z,theta_x,theta_y]^T，第i个支承点在板上的小位移为

    delta_i = z + y_i*theta_x - x_i*theta_y = b_i*q。

若三处补偿器仅是无质量线性弹簧、基座固定、只考虑上述三个刚体自由度，则

    M_q*q_ddot + C_q*q_dot + B_s'*diag(k_1,k_2,k_3)*B_s*q = B_u*u。

这是三自由度模型，总共只有三个机械固有模态。它可以容纳十几Hz的三组整体运动，但不能同时产生额外三个120–150Hz分量。若后者属于机械结构，须增加补偿组件/端座的局部惯性和变形、分布质量、其他台体自由度或基座动态。

一个可检验而非已证实的最低阶扩展，是给三个组件分别增加一个局部坐标eta_i，与q共同组成六自由度系统。它可能同时存在三组较低的整体运动和三组较高的局部耦合运动；频率分组需由参数决定，不由自由度计数保证。所有模态是整体耦合结果，不能将124.6、128.2、137.8Hz依次指定给上、左下、右下组件。

“以台体倾转为主要观测图样的三点补偿支承局部耦合动态”是待检验机制之一，不能将其提升为已经确认的零件模态。原有跨位置MAC、频移、Welch检查数值未改变。

验证对象具体化为三处补偿组件的两端：在统一参考激励下测100–160Hz运动端/固定端的振幅和相位，并与板主体、基座对照。如果共振处有显著局部相对运动而板主体近似整体运动，才形成装配归属的直接证据。仅在输入输出拟合中增加三阶不能替代这个验证。

## 片簧确认与低/高频解释的边界

真实片簧既提供等效静刚度，也具有分布质量和多个方向的柔度。某一个片簧—负载系统可在低频以负载整体运动为主、高频以局部或其他方向运动为主。因此“低频模态与片簧有关”既不证明、也不排除百赫兹分量与片簧有关。

若仅考虑q=[z,Rx,Ry]和三个无质量弹簧，模型只有三个机械模态；加入真实台体其他三个整体自由度后，即使还将片簧视为集中刚度，也可能出现额外的受约束运动。再考虑片簧分布质量、局部变形及基座运动，才是更完整的装配模型。当前四路竖向相对位移没有直接测量局部应变或横向运动，不能在上述模型之间唯一选择。

因此，下一验证的目标应是区分“局部片簧变形”“其他方向整体运动”“基座/尺条端运动”，而不是只寻找支持某一既定弹簧解释的证据。未新增仿真、未改变已辨识参数，亦未把这些假设写入论文为已确认结果。

## 竖向执行器能否激励水平支承模态

用户进一步说明水平向没有伺服控制，并提出三片簧横向较硬、其工作点随z变化，百赫兹可能为水平受约束模态。该解释在动力学上可成立，但须存在激励与观测两端的耦合，目前尚未测得水平振型。

在质心参考下，理想竖向执行器k的力和力矩为

    F_k=[0,0,f_k]^T，r_k × F_k=[y_k*f_k,-x_k*f_k,0]^T。

因此A1/A2/A3/A4的竖向力可直接驱动z、Rx、Ry，安装点偏离中心本身不会自动产生Fx、Fy或Mz。电机方向误差是另一种直接水平力来源，当前未测，不作为既定事实。

将整体坐标分为v=[z,Rx,Ry]和h=[x,y,Rz]。若M、C、K在两组之间均完全分块，理想竖向输入只有v分量，则不会激励纯h模态；理想竖向光栅也不会观测纯h运动。三角布置本身并不保证耦合非零，对称装配可能消除部分交叉项。

若片簧的实际空间柔度、预变形、连接几何或装配差异使动态刚度交叉块Z_hv(s)非零，则频域下

    [Z_vv Z_vh; Z_hv Z_hh] [v;h] = [B_v*u;0]，
    h = -Z_hh^(-1)*Z_hv*v （在Z_hh可逆的频率点）。

这里水平外力可以为零，但水平位移不必为零。完整系统的模态由耦合矩阵决定，不应直接把Z_hh的零点当作已耦合模态极点。

更简单的两自由度说明是

    D_z(s)*z + k_c*x = F_z，k_c*z + D_x(s)*x = 0，
    D_z=m_z*s^2+c_z*s+k_z，D_x=m_x*s^2+c_x*s+k_x。

由此

    X/F_z = -k_c/(D_z*D_x-k_c^2)，
    Z/F_z = D_x/(D_z*D_x-k_c^2)。

k_c=0时，水平模态在竖向输入输出传递函数中约掉；k_c不为零时，水平占主导的耦合模态可以进入两条响应。该模型只是代数上的可能性证明，不使用实机参数，不算新增仿真或来源确认。

在对称机械系统、经典阻尼的解释性模态展开下，单模态从u_k到y_j的贡献为

    G_jk,i(s) = (c_j^T*phi_i)*(phi_i^T*b_k) /
                [m_i*(s^2+2*zeta_i*omega_i*s+omega_i^2)]，
    m_i=phi_i^T*M*phi_i。

只有当输入投影phi_i^T*b_k与输出投影c_j^T*phi_i都非零时，这个模态才出现在该输入输出通道。一般非比例阻尼可用左右复模态留数表达同样的激励/观测条件，不将上述实模态公式当作现有一般复模态模型的新假设。

“没有水平伺服”描述的是未配置相应反馈调节目标，不能等同于水平被刚性锁死、无水平振动或该模态对竖向执行器严格不可控。存在微弱模态激励能力，也不等于有足够的水平定位或跟踪控制能力。竖向反馈还可能经机械耦合间接影响这些模态，不能把它们视为必然完全不受反馈影响。

当前约128Hz分量在四竖向输出上的倾转图样，只说明被观测到的部分包含倾转；不能据此推断未测的水平运动大小。若“水平主导模态”假设成立，其完整振型很可能是水平运动和可观测倾转的混合，而非完全纯水平平移。

z变化可能经片簧预变形、应力刚度或连接几何改变切线刚度与耦合项，从而引起频移；理想恒定线性刚度模型不产生这种工作点依赖。升频方向仍须真实构型与参数确定。已有跨位置频移只支持该机制的相容性，不是因果证明。

最小辨别测量：保留当前竖向激励与四光栅记录，同步增加至少一处水平振动测量（水平加速度计或测振仪）；检查与竖向参考相干的百赫兹响应。出现同频相干水平响应会加强水平参与证据，但要判定“水平主导”仍需多个方向/位置的振型或装配模型，不能只比较未经统一量纲的幅值。
