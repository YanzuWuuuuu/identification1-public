# 结构约束的实测检验

2026-10-17。先在 z=0 实测数据执行有界实验，不改原始数据或 SRIVC 基线。目标是检验结构约束与相对时延更新是否改善弱通道预测及检查 FRF 上的双向串扰，而非仅改善物理矩阵总误差。

数据与前端冻结：复用 srivc_retest_20261016/model_z0.mat 的训练/检查 FRF、输入倍率更正、逆幅值目标权和频率网格。检查段已经用于此前开发，只称记录内留出开发检查。新记录没有可恢复独立外激励的日志，本轮不是闭环无偏 IV/GMM 验证。

预设候选：B0 原自由分子 SRIVC；S1 固定 SRIVC 极点及时延，共同三维实支承空间+高频复留数秩一；S2 同结构，释放七个可加通道时延参数。支承前三阶复留数在共同左右三维空间中，约束实留数之和为零，消去该支承块的高频 1/s 项。这个必要结构松弛不是完整三自由度二阶机械实现，不能移植完整模型的所有证明。高频全部十二个分量先统一秩一，遇到簇或背景不适配时如实报告，不按检查误差挑选例外。暂不加滤波参数，先检验已存在的时延结构。

实现：SRIVC 结果提供极点与留数初始化；结构细化用解析 Jacobian 的阻尼 Gauss–Newton/信赖域最小二乘，先核验导数。两阶段各最多 120 次迭代，一个规定起点。固定极点不是重新执行全参数 SRIVC。保留数值停止状态，不将达到迭代上限写作收敛。

评价：用同一固定几何坐标比较物理、逻辑、N→N、N→逻辑、逻辑→N 的复 FRF 预测误差；用同一检查 FRF 比较几何校准、仅更新静态零空间、同静态方向再加相对时延校准。输入/输出向量固定单位范数。频带预设 3–25、25–80、100–170、260–310、25–800 Hz；同时给出目标共振保留和完整幅相图。NN 变小本身不是改善。纯时延补偿离线相位对齐等效于补到共同最大时延，额外共同相位不改变幅值与噪声增益。

停止：完成 z=0 两个候选的实际优化和公平检查，再决定是否有必要在其他位置做迁移检查。若结构约束失败，保存失败结果和原因，不无限改权、增阶或在开发检查段上择优。所有对实机效果的结论限定为离线检查 FRF 的预测。

训练边界检查修订：首次时延阶段两项碰到首行总时延 0.3 ms 下界。因此保存 initial_bounds 原运行，改为首行总时延 [0,1.2] ms、其余输出相对偏移 ±0.6 ms 再跑同一预设起点。此举由训练参数贴边触发，不依据检查误差挑模型。最后另检全部通道总时延非负性；如有负总时延，不能接受为物理时延估计。

强基线补充：为防止把普通静态校准已能做到的收益归于复杂结构辨识，另加入训练 FRF 在预先规定 25–80 Hz 内的最小交叉能量实零空间方向（4×4实对称矩阵最小特征向量）。仅训练数据求方向，检查数据评分；不取代或选择上述结构模型，不改权、不改极点。这个基线可能同时抑制柔性响应，必须与相同目标频带NN响应一起报告。

求解停止复核：标准设置的各候选以代价变化停止，一阶最优性未到 1e-7。对 z0 追加一次规定的严格复核：FunctionTolerance 从 1e-10 改为 1e-14、StepTolerance 从 1e-9 改为 1e-12，仍各阶段120次上限、同一初始化。standard_tolerance 保留旧z0结果。判断此前负结果是否主要由过早停止导致；不改数据、权重、频率或模型阶数。
