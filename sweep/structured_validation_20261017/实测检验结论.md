# 结构辨识与零空间校准：五位置实测检验

日期：2026-10-17。数据来自片簧紧固后的五位置记录，z=-0.6、-0.3、0、+0.5、+1.0 mm。

**结论：本轮确实运行了结构约束优化及相对通道时延更新。低频静态零空间更新有离线收益，但时延补偿没有带来进一步收益；结构化候选没有解决弱零空间传函的预测误差，也没有优于简单的训练频带静态校准。因此，目前不能把这一实现写成“已经实现宽频双向隔离”或“已证明新算法优于现有方法”。**

## 实际做了什么

1. 保留原自由分子加性 SRIVC 为基线，读取同一份训练/检查 FRF，使用相同频率、输入标度和逆幅值目标权。原始 MAT、原 SRIVC 模型均未修改。
2. 将 SRIVC 的十五个二阶分量精确转换为复极点对/留数形式。转换相对误差约 1e-15；解析 Jacobian 三方向差分核对约 3e-10。
3. 前三低频分量施加共同实三维左右空间，并约束实留数和为零，消去该低频块的高频 1/s 尾；其余十二个分量的复留数施加秩一。先固定原时延，再释放七个可加通道时延自由度。
4. 固定现有 SRIVC 极点，运行有解析 Jacobian 的信赖域最小二乘。这里是 **SRIVC 初始化后的固定极点结构细化**，不是再次执行全参数 SRIVC，也不是完整的参考信号 GMM。
5. 由训练得到的空间提取零空间，将静态校准、同一静态方向加因果时延对齐施加到同一检查 FRF。没有用拟合模型自身的代数零值作效果证据。
6. 增加简单强基线：在预设 25–80 Hz 训练 FRF 上直接最小化交叉能量，求实对称矩阵最小特征向量作为静态零空间；方向冻结后用检查 FRF 评分。

原数据每条记录去掉首秒后前半训练、后半检查。后半已在此前开发中多次查看，所以这是**记录内留出开发检查**，不是独立盲测。新数据只有闭环电机总指令和输出，没有独立外激励及完整反馈日志；不能从本轮推出闭环无偏性或实机控制效果。

## z=0：把静态收益与时延收益分开

25–80 Hz，同一检查 FRF、固定单位范数端口，表中数值是相对原几何矩阵的交叉响应 RMS 降低量，越大越好。

| 方法 | 零空间输入→逻辑输出 | 逻辑输入→零空间输出 |
|---|---:|---:|
| 结构辨识后仅更新静态零空间 | 4.16 dB | 9.50 dB |
| 同一静态零空间再加相对时延补偿 | 4.02 dB | 9.41 dB |
| 简单训练频带静态基线 | **5.52 dB** | **11.17 dB** |

因此静态方向确实可改进，但时延补偿在这个频段略差于只做静态更新。复杂结构辨识没有赢过简单静态基线。不能把与原始几何矩阵相比的全部收益都归于新辨识算法。

校准计算的输入、输出方向各自单位范数，名义逻辑方向始终相同。时延补偿采用各侧补到共同最大时延，幅值增益为1。该规范防止靠任意缩小输入/输出增益制造“泄漏下降”，但不是实际噪声谱已经测过不变的证明。保存的 Ty_unit/Tu_unit 是用于公平比较的规范化矩阵，不能直接当作保留原逻辑单位和控制增益的实机替换矩阵。

## 五位置结果

下表仍为25–80 Hz串扰降低量，顺序为“零空间输入→逻辑输出 / 逻辑输入→零空间输出”。

| z / mm | 结构静态 / dB | 结构+时延 / dB | 简单频带静态 / dB |
|---:|---:|---:|---:|
| -0.6 | 4.81 / 8.26 | 4.47 / 8.16 | **5.50 / 11.45** |
| -0.3 | 5.77 / 7.48 | 5.41 / 7.40 | **6.03 / 11.44** |
| 0 | 4.16 / 9.50 | 4.02 / 9.41 | **5.52 / 11.17** |
| +0.5 | 4.87 / 10.68 | 4.86 / 10.67 | **5.90 / 10.98** |
| +1.0 | 3.79 / 10.31 | 3.67 / 10.24 | **5.89 / 10.81** |

五个位置现象一致，不能解释为只有某个位置没调好。该表不代表零串扰；还需结合绝对响应、目标响应和工作输入幅度判断工程阈值。

## 辨识准确度没有被结构约束普遍改善

统一使用固定原几何矩阵评价预测，不能让每个候选换坐标后再比较误差。25–800 Hz z=0复频响误差：

| 响应块 | 原自由 SRIVC | 结构+更新时延 |
|---|---:|---:|
| 物理4×4 | 4.09% | 4.33% |
| 固定逻辑3×3 | 4.82% | 4.86% |
| 零空间→零空间 | 43.36% | 43.86% |
| 零空间→逻辑 | 32.77% | 30.28% |
| 逻辑→零空间 | 6.99% | 5.59% |

有两类交叉块的温和改善，但总体及NN误差未改善。五位置的结构候选物理误差4.12%–5.06%，均高于对应原SRIVC；NN仍约40.87%–57.83%。同记录两半NN差约9.20%–14.02%，也明显大于物理矩阵的约1%，说明弱通道更难确定；但这个分段差不能当作已知噪声下限，更不能据此把全部剩余误差都归因于噪声。

z=0的25–80 Hz NN预测误差约101%，100–170 Hz约100%，260–310 Hz约20.8%，470–515 Hz约5.4%。因此“全部柔性模态都没辨识到”不准确：主要共振仍有响应，但低频及百赫兹弱方向的复频响未拟合好。完整幅相和复残差图均保存；低信噪/近零响应的相位独立展开可能积累很多360°绕转，不能把这种绘图绕转直接解释为物理时延。

## 不能只看低频表

z=0结构+时延校准在100–170 Hz的两个交叉响应分别增加2.07、1.04 dB；25–800 Hz全带仅降低约0.14、0.08 dB。这里的交叉块同时包含实际柔性及其他机械响应，并不等于纯刚体泄漏。共同低频支承空间本来就不保证其他模态全部隔离。

260–310 Hz检查NN响应相对名义几何矩阵的RMS比值：

| z / mm | 结构+时延 | 简单频带静态 |
|---:|---:|---:|
| -0.6 | 78.7% | 93.6% |
| -0.3 | 83.3% | 103.4% |
| 0 | 106.8% | 106.0% |
| +0.5 | 133.6% | 113.0% |
| +1.0 | 106.6% | 106.3% |

这是完整观测频带响应的变化，不是孤立单模态保留率。不能把大于100%称为噪声放大，也不能只因峰仍存在就声称模态形状/相位完全保留。负位置的下降尤其应保留在报告中。

## 求解和结构检查

- 首次时延上下界过窄，训练参数贴下界；保存 initial_bounds 后放宽边界复算。最终所有五位置总通道有效时延为正，范围约0.261–0.428 ms。它们是当前模型下的有效拟合参数，不能直接解释成分别测准了电机和光栅硬件绝对时延。
- z=0追加严格求解复核：代价停止容差1e-10→1e-14、步长容差1e-9→1e-12。最终时延联合阶段exitflag=1，一阶最优性约2.39e-8，达到设定1e-7门槛，以上结论不变。因此z=0最终候选的负结果不能简单归因于该阶段没有求到局部驻点；仍不保证全局最优。
- z=0固定时延阶段及另外四位置标准设置仍以代价变化停止，并非均通过严格一阶门槛。状态原样保存，不声称全部严格收敛。
- 低频块的共同空间+实留数和为零只是必要结构松弛。每阶3×3内部复留数可满秩，不能称为严格六状态/三自由度机械模型，也不能替代完整物理模型的可辨识性证明。
- 固定高频十二分量全部复秩一，包括接近模态和宽背景；真实数据是否满足这些简单模态假设还未证实。这与固定极点、闭环FRF前端误差、任务权重不足一起构成待区分原因，当前不能锁定其中一个。

## 对论文和下一步的实际判断

静态零空间校准有工程用途，但**本轮没有证实结构+时延方法的新增优势**。简单频带基线在当前任务上更好，必须保留为正式对照。现有数学结论是条件结论，不能自动转成实测效果。

下一步应聚焦一个问题：让辨识目标真正约束“要保留的柔性响应与两向交叉响应”，并与上述简单静态基线比较；需要区别可抑制的低频支承泄漏与真实额外机械模态的交叉响应。继续堆叠时延/滤波参数或只降低整体4×4拟合误差，不足以解决这里暴露的弱方向问题。若做闭环IV/GMM的无偏实验，则须补录独立激励或可精确恢复它的完整反馈信号；现有数据仍可用于开发诊断。
