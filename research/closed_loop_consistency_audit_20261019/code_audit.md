# 闭环频域加性 IV/SRIVC：数值证据审计

日期：2026-10-19。审计对象为项目根目录《闭环一致性_频域加性SRIVC_数学推导与验证.md》；原文和原程序未修改。

## 结论

1. **MIMO 的 100 次结果确实存在，主要均值、标准差和 RMSE 可以从保存结果重算出来。** 它们支持“在所选闭环支承模态仿真中，参考 IV 比直接方法的阻尼偏差小”。没有发现把一阶公式直接当作 Monte Carlo 结果的情况。
2. MIMO 求解器实际是 **非线性频域 IV–Gauss–Newton**，每轮更新参考工具变量；它不是冻结真值工具变量。但尚未证明它与拟接入的 MATLAB 频域加性 SRIVC 算法具有完全相同的有限样本固定点，也未保存完整 score 证书。
3. 当前实验依赖**接近真值的极点初值、已知真控制器、由真 FRF 构造的逆幅权**。这适合检验局部偏差机理，不能作为盲辨识和工程算法已闭环的证据。
4. “精确极限根”和 Monte Carlo 的激励谱不完全相同，不能把二者差距全解释为有限样本非线性；“参考法全部在 1–2 个标准误内无偏”也不准确。
5. 没有数据长度增长实验、正态性/覆盖率实验、未知控制器实验、双积分加瞬态完整 MC、实测参考 IV 对照。上述内容应列为未验证，不能从当前结果推出。

## 1. 文件与真实运行内容

代码实际位于 `research/closed_loop_consistency_20261019/code/`，不是根目录 `code/`。存档有 `mcA.npz`、`mcB.npz`、`mcC.npz`、`mcD.npz`，分别 15、15、35、35 次，每文件四种方法，每行保存 3 个对数频率误差、3 个对数阻尼误差和迭代编号。

### MIMO

- `run_mc4.py:11–15`：每轮参考输入由当前模型计算 `inv(I+K*G(beta))*D`。
- `run_mc4.py:29–31`：频率和阻尼以真值为中心作 0.3% 和 15% 随机扰动；留数和瞬态经线性拟合初始化。
- `cl2.py:127–148`：按 `Re sum Z^H W J` 和 `Re sum Z^H W E` 做 IV–Gauss–Newton 步，所有 126 个参数同时更新；并非只更新极点或冻结留数。
- `cl2.py:135–136`：工具变量是包含瞬态项的完整输出梯度，用参考输入替换实测输入。它比正文式 (3.1) 中只写 `d(G Uhat)/d beta` 更完整；若正文把瞬态也算入 beta，则原式给瞬态参数的工具变量列为零，必须修正定义。
- `cl2.py:144–147`：只按极点参数步长停止；没有完整矩方程 score、留数步长、瞬态步长、最终残差验证。
- `run_mc4.py:39–41`：未保存最终全部参数，因此现存 NPZ 不能补算最终 score。
- README 要求 `NOFLEX=1`；`cl2.py:22–25` 据此只保留三个 10.6/11.7/16.1 Hz 支承模态。该 MC **没有刚体双积分，也没有高频柔性模态**。真实留数秩一，但估计每阶两个自由 4×4 实矩阵，共 96 留数、6 极点参数和24瞬态参数。
- `predict2.py:54–55`：逆幅权来自真实模型，实际为每个输出行的 `1/sum_j |G_true,ij|^2`，不是逐 FRF 元素权，也不等同于此前实验使用的所有 Schur 权定义。

### SISO

- `fd_cl.py:22–36` 是更新分母/分子的频域精化 IV 迭代；参考输入同样随当前模型更新，不是 oracle 工具变量。
- 植物直接给定离散二阶分子分母；最后将离散极点取对数换为连续频率和阻尼。它是频域 IV 机理测试，不直接验证一般连续时间加性 MIMO 算法。
- `fd_cl.py:24` 固定运行 30 次；`pred_siso.py:19` 固定40次，没有收敛检查。
- `fd_cl.py:31` 使用三个瞬态基函数 `1/A,z^-1/A,z^-2/A`；而文中二阶分块引理只需次数不超过1的瞬态分子。多出的瞬态自由度需要说明。
- `pred_siso.py:15–19` 外层按频带分组，各组重新生成噪声/激励，不是“同一组数据只换频带”的严格配对试验。`fd_cl.py:48–51` 的方法对照则使用同一轮数据。
- SISO 只保存打印程序，没有保存该表逐次结果或运行日志；本次未重跑100/200次。

## 3. 极限方程对照存在激励谱差异

`cl2.py:170–185` 构造一个6 s随机相位多正弦，重复10次；300000点DFT中只有每10个频点中的一个有外激励。在单次试验中每条线的输入方向为一个4维向量，谱矩阵是秩一。

`predict2.py:9–13,30` 使用 `LINEMASK` 将周期谱线乘10、其他频点置零。`exact_limit.py:9` 则仅使用 `sd^2*dshape(zs)`，**未乘 LINEMASK**，实际求的是平滑连续谱激励下的总体矩方程。两个积分/离散和不是同一个实验设计。

因此文中“41.8% vs 47.7%的差距来自有限样本非线性”未被隔离验证。必须先让精确极限求解器采用同一激励谱；若固定一个多正弦波形重复，还应区分条件于实际谱线方向的总体矩方程与随机相位集合平均矩方程。当前不能把全部差距归因给非线性。

这里也影响一致性定义：增加周期长度（更多频率线）与固定周期长度、仅增加重复次数是两种渐近序列。后者应采用离散谱线求和版本，不能直接诉诸带连续谱密度的积分极限而不说明。

## 4. 协方差证据的边界

- `predict2.py:6` 只取102个非瞬态参数，协方差不包含24个瞬态参数及其有限样本消元效应。对稳定对象的渐近忽略可以成立，但需先说明条件；不验证双积分/非平稳对象的版本。
- `predict2.py:30` 使用随机相位集合的对角输入谱矩阵；单个多正弦实验的逐线方向不是该对角矩阵。因此预测值与随机相位MC的有限样本方差只作近似比较。
- 参考 IV 的协方差构造具有合理形式。直接法的工具变量与噪声相关，`predict2.py:43` 对两法一律使用 `0.5 Re Qz^H Qz`，不能未经额外计算把直接法输出的标准差解释为正确 sandwich 协方差；幸而原表只引用参考法预测标准差。
- 没有覆盖率、分位数或标准化误差检查。参考均匀权第三阶实际sd1.1067%、报告预测约1.3%，参考逆幅权第二阶实际sd2.7788%、预测约2.4%，只能称量级接近，不能写“协方差已充分验证”。
- 所有MC只有N=300000，没有均值收敛和方差随N下降曲线，因而是固定样本性能证据，不是数值上的一致性验证。

## 5. 其他未形成可复现实验链的断言

1. 原文引理1后的“不加瞬态8%、加后9×10^-13”：当前代码包有模型和瞬态构造，但没有对应运行入口、数据/随机种子、结果文件。可以再做一项小型确定性单元验证；不能把函数存在当作数值已复核。
2. 9.3刚体+五柔性只提供 `predict.py` 真值处一阶偏差预测；未提供该案例MC。其标题和结论应明确为“理论预测对照”。
3. 第10节15.30%的旧实测数据诊断没有相应脚本或结果文件。`design3.py` 只计算模拟对象的谱功率，不是实测周期分组。这个诊断即便复现，也必须将周期不重复量与随机反馈噪声区分，并排除漂移、非周期干扰、周期对齐错误。
4. 已知控制器直接来自仿真真值；“由实测反馈指令精确恢复控制器”没有数值检验。
5. README 给出单次25轮命令，但存档是15+15+35+35，未记录四批精确随机种子、环境、命令、依赖版本及原始日志。可复现方法，但不能逐位复现现有100次存档。

## 6. 足够聚焦的修补建议

1. 正文把当前算法准确称为“参考输入驱动的频域加性 IV 矩估计/IV–Gauss–Newton”，另外给出与实际加性SRIVC固定点等价的代数证明和数值score交叉核对。
2. 同一闭环支承模态、同一带宽和噪声设置即可，不必扩展更多平台；补少量N增长点，并保存每次最终参数、score、稳定性、失败率和标准化误差。
3. 修正精确总体矩方程的激励谱，使其与MC多正弦完全一致；将参考法的微小有限样本偏差保留在报告中。
4. 将真值权重/初值明确标为理论验证设置；另加数据可获得初始化和独立估计权重的小型对照。
