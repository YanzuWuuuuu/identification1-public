# 独立只读核查

审查覆盖变量投影、秩 1 坐标、P6 判据、P7 Monte Carlo、周期 DFT 删除与 nested jackknife、残差期望。审查者未修改代码或结果。

核查认为：

- 剖面求解保留原参考 IV 矩方程；两项原根一致性验证均达到 1e-8。
- 秩 1 共用振型的坐标映射及导数正确，nested delete-two 的修正估计量 SE 构造正确。
- 原 P6/P7 数值阈值未改动，MC 的失败有限端点仍在统计中。

指出的问题及处理：

1. M1 是全频点拟合，不能使用仅谱线的 M3 残差算子计算其 E[Q]。现入口对非 M3 显式报错，P6 主残差表仅给 M3。
2. 内层工具迭代失败时不会进入外层 hybrid。报告已纠正，不能把未满足线性矩的点称为剖面根。
3. log 空间去偏后指数回变换仍可能产生 O(1/P) Jensen 偏差。报告明确区分有限 MC 门槛与渐近阶数，CSV 保留回变换分量。
4. 低频自由模型某些 E[Q] 极大，Q/E≈1 不代表绝对残差很小。新增 Q、E[Q]、数据维数 n、E[Q]/n。
5. 高频锚定公共时延后的低频 SE 是条件 SE，报告明确未传播锚点随机误差，不据此声称总体精度改善。
6. `delay_residual_fraction` 是剔除非时延参数后保留整组时延的剩余比例，未剔除其他六个时延；它不是单个时延的边际有效信息，且未用于 P6 判据。
7. P6(c)/(d) 跨窗口公共时延一致性和 493 Hz 残差判据均不支持；P7 实测阻尼 16/18 通过而非全部通过。这些结论已明确。
8. M1 全窗口时延 SE 已加入单独批次和结果表；失败父端点不被赋予有效误差棒。
9. 新增 M1/M2 固定非线性参数的一次线性剖面求解；两个原根基准差分别为 9.05e-11、3.77e-13。仅在线性块可辨识时保证参数根唯一，秩亏下不同最小范数选择可能有不同零空间参数。
10. 低频重做仅 A_nominal 与 A_highgain 的全部父端点及删周期折有效；配对差 SE 分别增大 2.99% 与 14.81%，不支持不确定度下降。
11. P7 主判据运行前解释为两个 SE 的平方和开根，未包含同记录两估计的协方差。按此冻结门槛实测阻尼 16/18 通过，但按同折差值 SE 检查只有 5/18；报告同时列出，不声称统计等价。
12. 最终清单逐父端点核查预期折：M1 465/465（4 失败），M3 472/472（0 失败）；失败父端点分别有 27、20 折未运行，单独列示。P7 仿真 120 条、240 个完整估计、1120 个删除周期估计齐全；实测 215 个拟合齐全。固定公共时延的 139 个折另列，不混入主分支。
