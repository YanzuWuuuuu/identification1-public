# 时延偏差总体矩阵与截断敏感性

这是原 375 参数模型的随机相位平均总体积分诊断，不是拟合结果，也不是某一条随机相位记录的条件预测。真值 C1=D0=D2=0，未人为添加背景。

采用 $\Phi_v=\sigma_v^2I+\sigma_w^2G_0G_0^H$、$S=(I+KG_0)^{-1}$、$F=SK$；输入信号谱为$\Phi_{u,d}=\sigma_d^2dshape\,SS^H$，反馈输入噪声谱为$\Phi_{u,n}=F\Phi_vF^H$。总体 $M$ 同时包含两项，$b_l=-\int\Re\operatorname{tr}(G_lF\Phi_v)\,df/f_s$。

保留全部模态瞬态列。随机相位平均将它们与动态参数的交叉块置零，瞬态自身 Gram 按原始 DFT 的 N² 归一化得到 1/N 系数，b 的瞬态块为零。这忽略有限记录状态边界与噪声的相关项，不能当作严格有限样本恒等式。

## 高频参数分块

高频目标为 286.573/344.945/490.390 Hz 的 log频率、log阻尼。先消去其余所有留数、背景、瞬态及其他模态极点，才分成
$\delta\theta_H=\bar M_{HH}^{-1}\bar b_H-\bar M_{HH}^{-1}\bar M_{H\tau}\delta\tau$。
JSON 中分别保留自身/其他耦合项、共享时延传播项、完整解以及分解误差。本平台 100–550 Hz 的回路增益并不满足 <0.1，因此不能预设第一项为零。

伪逆对全矩阵与各 Schur 子块分别截断时不一定给出相同解。若 5.3 与完整解差大，或改变截断/积分步长即大幅改变预测，应报告预测不能稳定计算，不能择取一个截断值作为精确理论预测。

另用 Cholesky 因子直接计算 Schur 块，避免显式逆与大数相减，核对理论分块与完整解。它是代数实现自检；病态矩阵偶然能完成Cholesky，并不证明所有弱方向可可靠辨识。

## 与单条实测 D 矩阵版本的区别

给定一条长度 N 的多正弦 D_k 时，信号部分应使用实际 U_d,k=S_kD_k，构造动态参数列与瞬态列，累加 Re(J_dᴴJ_d)/N²；它包含跨参数及动态—瞬态交叉块。再叠加反馈噪声期望项和 b。本脚本使用独立随机相位平均的 E[D_kD_kᴴ]，因此不对应 seed=1002 的特定相位，但可以检查总体偏差预测的秩和病态性。
