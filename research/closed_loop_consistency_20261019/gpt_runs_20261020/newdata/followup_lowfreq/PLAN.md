# 固定分析计划

只复用原 158 参数、3–25 Hz、精确 ZOH 模型；原数据及端点只读。写入前已计算全部受保护文件 SHA-256。

1. 复现旧 B 谱偏差；同记录非激励点残差按总宽 0.5/1 Hz 平滑，不新增收缩或正则。主判定用 0.5 Hz、(M-C) 版本，同时保留 M 版本。
2. 删除一个完整周期后拼接剩余周期，重新 DFT；每种方法固定使用该记录原来的 initial_beta，80 步、tol=1e-5、cap=0.05。所有失败保留，不用筛选成功样本构造主要 jackknife。
3. 复高斯噪声采用 proper 约定；实表示每频率为 Re(y1:4), Im(y1:4)。协方差为 N/2*[Re(Phi),-Im(Phi);Im(Phi),Re(Phi)]。冻结原 M3w 权重，不重新定义方法。
4. 200 次 bootstrap 只核对线性残差算子的条件期望，不充当包含失配、权重估计误差的完整置信检验。
5. 裁掉初始周期的主敏感性诊断保留原 M3 全部参数；另固定所有传递函数参数，仅重新估计原有 24 个瞬态系数，以检查改变记录边界的影响。后者单独标注，不替换主噪声谱或判定。
6. 图采用 Python quantitative grid；核心是检验预测与配对差是否相容、噪声是否足以解释残差。误差棒明确为周期 jackknife SE；PNG 300 dpi、PDF 可编辑文本。失败和弱检测效应在图注中保留。

预设判定不改：四条 nominal/highgain 记录第二阶预测/实测均在[0.67,1.5]；第二阶 |z|<2，低检测力的第一三阶实测不超过2SE；Q/EQ<=2。
