## 3. 模型求值与控制器接口

只读导入`followup_DE/real_d/realfit_extended.py`和`loader_copy.py`；导入前`sys.dont_write_bytecode=True`，避免改写旧目录pycache。

```python
ctx = m.Ctx(f_hz, load.TAU - m.Ts/2, "zoh")
G = m.resp(ctx, beta)                # K×4×4, excludes record transients
Yhat, J = m.out_jac(ctx, beta, U)   # includes modal transients
data = load.prepare(z, 8, 1)
K = -data["Q"][None] @ data["kv"](ctx.zi)
```

- 158参数：前96为3模态×2留数×4×4；D0/D2各16；logω索引128:131；logζ索引131:134；瞬态索引134:158，共3×4×2。瞬态为(t0+t1 z⁻¹)/a(z⁻¹)，常数项不得删除。
- ZOH仅用于3个模态块；D0、D2背景仍沿用带限CT形式。时延矩阵统一减100µs是已有有效时延的分配假设。
- M5的beta瞬态适配“每周期未归一化DFT均值”；M2/M3/M3w/M5n适配“全长未归一化DFT”。稳态FRF `resp` 可以直接比较；跨窗预测不能把这些瞬态参数直接混用。
- 控制器由当前窗的V←Y ARX(6,6)拟合，kv(zi)返回K×3×4，真实反馈符号为U=D+QV=D−KY。

## 5. 旧非参数FRF做法及本轮可继承点

- 代码：`experiment_data/srivc_no_lrm_20261015/run_recovered_reference_identification.m`。它先用局部频域有理回归估D→[V;Y]，再用精确静态分配构造Tud=I+Q*Tvd，最后G=Tyd/Tud。避免逐频求秩1的DDᴴ逆，也避免对接近单位阵的Tud另拟分母。
- 每个输出局部回归17参数：4输入×二次分子=12，3个瞬态多项式项，2个分母项。默认91个全长DFT频点窗口，旧30s记录约3Hz跨度。它不使用本轮SRIVC拟合的极点，因此可作独立的非参数参考。
- 但3–25Hz的支承峰宽小且相互靠近，3Hz局部窗本身可能引入平滑/有理逼近偏差。须记录局部回归rank/condition、Tud condition与窗宽敏感性；结果名称应为“非参数参考估计”，不得标成真值。
- 跨周期重复仅提高同一频点精度，不提供4个输入空间实现；频率局部共享光滑性是恢复4×4矩阵的额外假设。
- 若作前半模型对后半FRF，应采用P4/s1模型与P4/s5数据，或反向；全P8模型对同P8FRF是同数据拟合核查，不能声称独立验证。
- 旧局部回归在25Hz以上强制窗口限制到25–800Hz，而25Hz以下使用全正频；本轮若仅3–25Hz，应明确窗口是否允许跨界，避免边缘解释歧义。
