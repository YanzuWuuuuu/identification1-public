# 旧实测数据的非参数 FRF 参照：预先固定的范围

日期：2026-10-19。本文只补旧数据 FRF 参照，不修改理论、模型结构、已有拟合或数据，不新增硬件/MC实验。

主问题：闭环直接法、参考 IV 与 SML 的既有参数模型在 3–25 Hz 是否与独立构造的非参数 FRF 相容？非参数 FRF 是估计参照，不是真值；此分析不证明哪种方法更准确或一致。

数据：z=-0.5,0,0.5,1 mm；排除已知坏记录 z=-1。采用现有记录的第2–9周期，共8周期。全记录参照是同记录拟合检查；分段比较用前4周期参数模型对后4周期非参数 FRF，并作反向检查（若模型可用）。固定通道时延为此前估计，不能称全流程完全隔离的盲测。参考输入 D 源自记录，FRF计算不使用任何参数模型的极点、留数、时延或控制器。

非参数估计：以参考 D 为回归输入，对8个闭环输出 [U,Y] 作局部多项式回归，包含局部多项式瞬态；得到 T_ud,T_yd，再计算 Gnp=T_yd T_ud^(-1)。每条谱线仅一个输入向量，不能直接逐线反演4×4矩阵。完整FRF依赖邻频平滑与局部激励满秩，不是无假设恢复。

预设主配置：多项式阶次2、21条相邻激励谱线（频宽约3.33Hz、15个复回归系数/输出，包含3个瞬态系数）。敏感性配置：阶次1/15条、阶次2/31条。边界使用同数量单侧窗口并标注。不得按哪个参数模型更好看来挑选窗口。局部设计缩放列后用SVD/QR最小二乘，不正则化T_ud求逆；保留并报告病态和失败。

精度检查：原数据参考重复性与单线秩；局部回归秩和条件数；T_ud条件数；窗口敏感性；各周期估计传播得到的复FRF标准误（仅随机散布，不含平滑偏差）；前后半段FRF差异。必要时使用明确标注的分辨率诊断，不改主配置去迎合曲线。

参数对照：M1全部频点直接IV、M2谱线直接IV、M3参考IV、M3w参考加权IV、M5周期SML、M5n邻点权SML。重用相同ZOH模型；缺失的M1后半段仅按原方法补算，写入本目录。失败端点保留、标记、不作成功结果统计。模型FRF去掉记录瞬态项。

指标：复FRF Frobenius相对差（整体与逐通道）、幅值dB差、圆周相位差、逐周期随机散布、窗口差异；完整列出所有方法和失败。由于共用记录且仅4个位置，不做显著性/准确率结论。主差异解释需考虑平滑偏差、反演放大和参数模型失配。

图合同：Python/matplotlib（沿用既有Python工作流）；量化网格。主图为z=0的4×4幅值、连续展开相位和误差图，其余位置提供相同图；另给各位置摘要。灰色非参数参照、蓝色参考IV、紫色直接法、深灰SML，方法用线型辅助区分，不使用橙线。相位独立展开，仅允许每条曲线统一加减整周用于显示，误差始终从复比值计算。源数据npz/CSV、PDF/SVG/PNG留档。期刊投稿版排版可之后再精简。

资源：本机i5-12600KF、16逻辑线程；本任务单进程BLAS1线程、局部小矩阵处理，无需GPU或大规模重拟合。先z=0检查，再固定流程运行其他3位置。

论文映射：实验章“实测频响与非参数参照”；supporting证据。完成条件为可复现FRF、对照图、敏感性及失败记录、明确的可用性结论。理论主线按固定P路线聚焦；本轮不再扩展证明。

## 后续诊断记录（不覆盖以上预设）

首轮LPM显示参照两半差和窗口敏感性较大，因而增加局部有理LRM诊断，区别局部多项式逼近与闭环反演的影响。候选为二阶分子/分母/瞬态、21/25/31点窗，以及线性解或3次SK重加权。只用前4周期、四位置合并的留一激励频线预测，删除该频线所有周期输出，以固定逐输出噪声SE标准化，选择单一全局配置；后4周期未用于选择，参数化模型未输入该流程。最终linear/31点/SK0，对应5Hz跨度。LPM主结果完整保留。
