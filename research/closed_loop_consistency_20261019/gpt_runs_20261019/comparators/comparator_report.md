# 周期 SML 与间接 FRF 对照：审查与实跑结论

## 1. 完成范围与审计口径

本目录完成 140 个 SML 主拟合（P=2/4/8 各 40 次，P=16 共 20 次），100 个间接均匀权 IV–GN 拟合（P=4/8 各 40 次，P=16 共 20 次），60 个正则化间接协方差权 IV–GN 拟合（P=8/16 共 40/20 次）。另保存同一间接目标的 160 个信赖域最小二乘优化器对照，以及 12 个 SML、8 个间接协方差收缩敏感性拟合。每次拟合保存完整参数、初值、误差、状态、耗时；原始文件不修改。

主要统计在 `results_tables.md`，六个参数的完整均值±SE、SD、RMSE 在 `summary.csv/json`。统计包含所有有限端点，未剔除迭代失败或离群值；失败次数单列。未经正则的不可计算方案在 `availability.json` 单列，不能与求解失败混为一谈。

## 2. SML 公式核对与实现

周期确定性未知输入的剖面 SML 为

\[
V(\theta)=\sum_k e_k^H C_{e,k}(\theta)^{-1}e_k,
\quad C_e=C_Y-C_{YU}G^H-GC_{YU}^H+GC_UG^H.
\]

协方差先除以 P−1，再除以 P，正是周期均值的协方差。源文献为 Hong、Söderström、Schoukens、Pintelon，IFAC 2008 第 4 节式 (11)。这里不添加 logdet(Ce)：那会变成另一个似然设定。2007 EIV 论文的一般随机输入 ML 同时建模随机输入和噪声，并有行列式项；BJ Part I 的闭环 ML 亦不是直接把这里的 Ce 当作输出噪声的简单似然。

用户所述“冻结 Ce 再走一步”若完全忽略 Ce 的参数导数，通常不是上述 SML 的 Gauss–Newton 法。令 Ce=LL^H，r=L^−1e，本实现对整个 r 求导，包含 dCe。导数方向有限差分相对误差为 1.75×10^−5（原 cl2 极点导数本身采用 1e−6 前向差分）；无噪声均值数据的拟合响应恢复误差 3.53×10^−12，极点相对误差 5.58×10^−13。具体记录 `validation_sml.json`。

四输出模型的逐频 Ce 样本秩最多 P−1，因此 P=2/4 时不存在所要求的普通逆。不能为了得到一条曲线就静默使用伪逆。这里分开呈现：

- P=1：没有样本方差，原始 SML 不可计算。
- P=2/4：原始 SML 不可计算；`M5_reg` 用固定 α=0.1 对联合 [Y,U] 样本协方差做对角收缩，是明确的附加诊断方法。
- P=8/16：`M5` 直接使用完整 Ce，未加正则。

|M5_reg|2|40|0.843 / 2.675 / −0.046|15.745 / 10.014 / 1.356|0|
|M5_reg|4|40|−1.546 / 0.954 / 0.091|9.880 / 4.784 / 0.952|0|

所有主 SML 拟合均满足归一化全梯度 score≤1e−5。P=8/16 总体支持“周期协方差校正可大幅降低直接法偏差”，但不能写成每个有限样本均无偏：P=16 模态 1 均值 1.520%，SE=0.603%，为约 2.52 SE。20 次实验不足以据此证明渐近有偏，也不足以把它报告为精确零偏差。

收缩敏感性提醒不能把 M5_reg 冒称经典无正则 SML：同一 P=4 的前三个配对样本，α=0.01/0.1/0.3 时模态 1 阻尼均值分别为 19.16%/3.07%/0.78%。这只是 3 个样本的诊断，不构成重新调参的性能估计；主结果 α=0.1 未根据验证误差选择。

## 4. 间接 FRF 的实现与不可忽视的预算限制

每次只激励一个执行器，分别获得四列 U/Y/D；每条谱线计算 Tud=U D^−1、Tyd=Y D^−1、Ghat=Tyd Tud^−1。实际计算没有把 Y/U 逐元素相除。

FRF 误差一阶传播采用

\[
\delta G=(\delta Y-\widehat G\delta U)\bar U^{-1}.
\]

四次实验独立。第 a 次实验的噪声块通过 `(Uinv(a,:)^T kron I4)` 传播，保留同一个误差块产生的不同 FRF 列间相关性，得到完整 16×16 复协方差。其样本秩不超过 4(P/4−1)=P−4。所以用户指定的 P=4/8/16 三个预算下，原始 M6 协方差都不可逆；秩上限分别是 0/4/12，而不是 16。

因此完整间接比较是：M6u（不估计方差的均匀权）在三档都计算；M6_reg（α=0.1 对角收缩）只在 P=8/16 计算；原始 M6 不可计算。没有将 M6_reg 写成经典最优协方差权法。

原 `cl2.iv_solve` 的 `free` 模式会关闭极点导数并只做一步，且不支持全 16×16 协方差，因此不能直接传一个索引就实现用户要求的无瞬态 FRF 模型。新 `run_indirect_ivgn.py` 做最小适配：只估计 102 个结构参数，不含 24 个瞬态；保留原 IV–GN 更新、缩放与停止规则；Z 就是模型梯度。另一个信赖域优化器仅用于检验非理想结果是否只是原迭代未收敛。

无噪声 FRF 构造和 IV–GN 拟合核对：响应相对误差 7.69×10^−12，极点相对误差 2.62×10^−12。快速特征分解滤波仿真与原 scipy.dlsim 的相对差为 5.88×10^−11。上述记录在 `validation_indirect.json` 和 `validation_eigenfilter.json`。

记录样本数按要求完全匹配，但还有两个设计区别必须公开：四次单轴实验共丢弃 8 个预热周期，单次四轴同时实验丢弃 2 个；每个活动执行器幅值相同的情况下，间接法总输入能量约为同时激励法的四分之一。因此本实验评估的是“相同记录时长、相同单轴幅值约束”的流程，不是相同总激励能量的最优实验设计对比。

## 5. 间接 FRF 的实际结果并不符合预先期待

|主要 IV–GN 方案|P|次数|三个阻尼偏差均值 (%)|三个标准差 (%)|迭代失败|
|---|---:|---:|---|---|---:|
|M6u|4|40|−8.14 / −29.29 / 1.80|79.19 / 48.01 / 8.33|20|
|M6u|8|40|−24.33 / −12.42 / 1.35|49.94 / 28.47 / 5.48|6|
|M6u|16|20|−4.31 / −8.87 / 0.76|31.15 / 11.86 / 3.57|0|
|M6_reg|8|40|31.68 / 14.16 / 1.66|30.32 / 15.19 / 3.60|0|
|M6_reg|16|20|8.77 / 3.72 / 1.35|10.56 / 3.82 / 1.18|0|

M6u 的求解确实困难；换信赖域优化器后 P=4/8 的失败降到 3/40 和 1/40，但偏差及大离散仍存在。M6_reg 两种优化器结果几乎相同，表明其偏差不是简单换求解器就能消除。

支持以下分析，但不声称已唯一分离所有偏差来源：

1. 含噪 Tud 的有限样本逆并非无偏运算。控制带宽内的敏感度抑制，使某些频点的逆放大更明显。
2. 条件数的频点中位数约 3.55，但 P=4/8/16 最大值分别为 3444.94/1830.28/526.50。每次实验的最大条件数与阻尼误差范数的 Spearman 相关分别为 0.441/0.575/0.286，提示少数病态频点与异常误差有关。
3. 少周期下逐频样本协方差不足，收缩权改变了估计器。其权重也由同一份随机 FRF 估计，不能套用已知协方差的理想两阶段结果。
4. 模态拟合是非线性的；相邻支承模态的极点、留数和阻尼相互补偿，M6u 的有限记录异常值不能靠“理论间接法一致”直接忽略。

敏感性也支持保留上述限定：P=16 前两个配对样本的 M6_reg 模态 1 阻尼均值，在 α=0.01/0.1/0.3 时为 4.44%/10.27%/15.82%。这不是稳健最优权的证据。

## 6. SML 与间接 FRF 对比参考 IV 的优劣与适用场景

参考 IV 可以直接使用一次同时多轴实验、原始 DFT 和外加参考，避免逐频矩阵求逆，也不需要先估计每条谱线的噪声协方差；使用 D 本身作工具可不提供控制器，但有限样本方差和局部求根仍须检查。单周期数据“形式上能运行”不等于参数准确或收敛可靠。

周期 SML 不需要控制器，也不需要参数化噪声模型，但需要重复周期估计输入输出交叉协方差；本四输出逐频实现的原始形式在 P≤4 不可求逆，P=8/16 得到较好的统计结果。少周期收缩 SML 可以运行，但依赖额外正则假设，不能沿用经典无正则结论。

间接 FRF 不需要控制器或参数化噪声模型，其优点是获得可复用、可视化、能供多个参数模型共享的完整 FRF。代价是逐频输入方向满秩所需的四次独立实验，以及每次足够多的周期/实现来估计协方差。本次严苛的等记录时长预算下，每次只有 1/2/4 周期；有限样本逆、协方差秩不足和求解异常让它没有达到预期的无偏效果。不能据此否定文献使用 10 周期×10 实现的间接流程，也不能将其优点预先写成当前数据已验证的结论。

结论应按完整主实验 A 与本对照共同表述。这里支持“重复周期充足时 SML 是有力替代”，支持“间接流程在少周期固定预算下存在额外统计和数值负担”，不支持“当前所有间接 FRF 结果均无偏”，也不支持未经检查就声称“只有参考 IV 在单周期/少周期能用”。
