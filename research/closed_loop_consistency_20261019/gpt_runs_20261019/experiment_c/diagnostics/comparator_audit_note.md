# 对照方法代码独立复核

复核范围：`comparators/run_indirect.py`、`run_indirect_ivgn.py`、`sml_core.py`。只读原实现；测试及结果写在本 diagnostics 目录。

结论：没有发现输入输出单位、协方差传播的向量化次序、均值协方差归一化或白化雅可比公式错误。未见将失败伪装成零误差的处理。数值检查见 `comparator_independent_checks.json`。

## 核对结果

- 间接法每个矩阵的列是一次独立单轴激励，行是物理通道。`Tud=U D^-1`、`Tyd=Y D^-1`、`G=Tyd Tud^-1=Y U^-1` 的乘法次序正确；D 的单位与缩放自然消去。
- 一阶传播为 `deltaG=(deltaY−G deltaU) U^-1`。代码 L 对应 `(U^-1的第a行)^T ⊗ I`，作用于第a次实验的四输出残差。它采用列优先 vec；拟合残差通过 transpose(input,output) 后 reshape 也采用相同 vec，顺序一致。
- 协方差分母 `p(p−1)` 是 p 个周期均值的协方差，不是遗漏 P；以投影后的周期残差直接重算与四个协方差项相加，误差约 1.99e−16。
- 四次实验各 p=P/4 个周期，原始16维FRF协方差秩不超过4(p−1)=P−4。在P=4/8/16时不可能满秩；将其标记不可用是数学要求。10%收缩版本必须单独称 M6_reg，不能称原始SML或无偏最优权。
- FRF 拟合将瞬态参数固定为0，只更新96个留数与6个极点，共102个参数；`gmodel_from_output` 还通过零输入输出相减去除了瞬态贡献。模型线性初始化的通道顺序也与参数布局一致。
- SML 使用参数相关残差协方差的完整白化导数，包括 Cholesky 因子导数；人工构造的非线性模型中央差分相对误差 1.1e−9至1.9e−9，白化二范数与二次型差1.27e−16。它不是冻结协方差后仅求残差导数的迭代。
- FRF 一阶传播算子与直接矩阵公式误差1.29e−16，实际比值有限差分检验误差9.14e−8（步长1e−7）。
- 加速仿真对状态空间 `dlsim` 的相对差4.20e−11，未发现离散时间的一拍偏移。

## 报告应明确的限制

1. 比值FRF在有限周期下仍是非线性随机比值；这里的协方差也是一阶 plug-in 估计。不能把“间接法一致”说成任意小P严格无偏。
2. 四次实验总记录长度与单实验相同，但实际采集还包含每次2个丢弃周期：间接法共8个预热周期，单实验共2个。报告公平性应称“等保留数据量”，另列预热与重新激励的开销。同一单路激励幅值下，单轴方案总激励能量也只有同时四路方案的四分之一；因此方差差异不能全部归因于估计器优劣。
3. LM/TRF 版本与规范 IV–GN 版本必须分开标记；两者优化同一个加权FRF输出误差，但有限迭代预算和全局化策略不同，结果不能混成一种算法。
4. `run_indirect_ivgn.py` 在导入 `run_indirect` 设置线程环境之前已导入 numpy。启动器应提前设置 `OPENBLAS_NUM_THREADS=MKL_NUM_THREADS=OMP_NUM_THREADS=1`，避免不同机器线程超额导致耗时失真。这是运行性能问题，未发现数值公式错误。
5. 真正周期稳态测量的均值协方差理论通常依赖周期噪声近似独立。仿真每周期6秒且预热2周期，但并未从样本协方差本身证明独立性；精确有限样本无偏说法仍需收敛/统计证据。
