# 一般加性模态化：范围与修改记录

## 一句话主线

对存在通道动态差异的多变量加性模态系统，联合估计机械结构和相对通道动态；在含刚体双积分的冗余子类中，从同一估计恢复零空间投影和相对动态，并建立其误差与解耦泄漏的联系，以已有柔性平台数据检验用途。

## 模型层次与符号

| 符号或术语 | 本稿定义 | 与原稿的区别 |
| --- | --- | --- |
| 一般加性模型 | P 为多个共享标量分母的矩阵子模型之和 | 先定义模型族，再施加模态结构 |
| n_y、n_u | 任意输出数与输入数，允许不相等 | 原四路设定移至算例 |
| n_r、r | 刚体传递矩阵的秩、柔性模态数 | 原三刚体、五柔性设定移至算例 |
| M | n_y × n_u、秩 n_r 的刚体矩阵 | 数据识别的是总矩阵，不唯一分解各个同极点刚体因子 |
| N_y、N_u | 左右零空间正交基矩阵 | 原一维零向量推广为多维子空间 |
| Π_y、Π_u | 基旋转不变的零空间投影 | 不将任意选定基当作唯一可辨识量 |
| R_i | 简单柔性极点的秩一复留数 | 保留一般阻尼模型和实系数映射 |
| Γ | 零空间投影和同侧相对动态 | 仅对具备对应刚体结构的子类主张已证明的唯一性 |

## 正文重组

- 第 2 节：一般加性表示 → 机械模态约束 → 通道动态 → 相对目标 → 一般尺寸闭环观测。
- 第 3 节：图连通和结构证明、参数计数、线性初始化、秩坐标、Jacobian、约束迭代与统计条件均采用一般维数。数值尺度、特定初值和停止容差移入第 5 节。
- 第 4 节：非方阵和多维零空间下重新写出静态二阶界、动态分块界和投影导数。柔性保留采用指定输入方向的范数下界；全方向保证需额外最小增益条件。
- 第 5 节：明确 n_y=n_u=4、n_r=3、r=5 是算例，125 个参数和 6272 维残差是通用公式的具体取值。原图表块逐字保留。
- 标题、摘要、引言和结论围绕多变量加性模态辨识重写；原详细大纲和论文梗概不修改。

## 参考材料与方法边界

已重新阅读用户指定 MSSP 2026 论文《Structured identification of multivariable modal systems》第 3–5 页的模态模型、自由加性模型和结构映射。沿用的是先定义一般模型再施加约束的组织方式，正文保留对该论文的引用。本稿仍为原始闭环数据上的联合结构化最小二乘，不将初始化和秩投影描述为已经实现该文的 RIV/IPEM 两阶段方法。

广义加性表示不等于本文已解决任意阶次、任意滤波、无刚体项或有低频刚度系统的时延唯一性。现有定理依赖刚体双积分、非实柔性极点、规定通道族、图连通和无消去；物理可分离通道族的全局唯一性与扩大系数族的局部正则性分别陈述。有限设计一致性仍有明确的目标唯一性和求解条件。

主验证仍是已有五模态平台的合成闭环数据。没有新增性能实验，没有将通用公式的数学核对称为多系统辨识验证，没有改变图表数据或宣称新增硬件证据。

## 数学核对

记录见《一般加性模态化_数学核对_20261014.json》。用固定随机种子，对尺寸 (n_y,n_u,n_r)=(4,4,3)、(7,5,2)、(5,8,3)、(6,6,1)、(2,3,1) 各构造 6 个代数实例，总计 30 个。核对固定秩坐标微分、左右投影微分、复留数 Kronecker 映射、非方阵闭环微分、静态及动态泄漏界和指定方向柔性下界。所有检查通过；最大微分相对误差约 1.58×10⁻⁹，所有实际泄漏均不超过相应界。这些核对辅助排除尺寸与代数实现错误，不替代正文证明或识别性能实验。
