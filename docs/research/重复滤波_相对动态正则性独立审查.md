# 公共或重复一阶滤波下：相对动态目标的正则性独立审查

日期：2026-10-13。仅作解析推导与证明审查；未运行仿真、数值辨识或数值代数。

## 1. 需要避免的错误推论

考虑
\[
G_{jk}(s)=e^{-s\ell_{jk}}\frac{P_{jk}(s)}{(1+t_{y,j}s)(1+t_{u,k}s)},
\qquad \ell_{jk}=\tau_{y,j}+\tau_{u,k}.
\]

当所有时间常数均为同一个正数 \(t_0\) 时，扰动
\(\delta t_y=c\mathbf1,\delta t_u=-c\mathbf1\) 是观测映射的一阶零方向。但它一般不是精确的连续规范，因为
\[
(1+(t_0+c)s)(1+(t_0-c)s)
=(1+t_0s)^2-c^2s^2.
\]

因此，不能把这个方向直接删除后便套用通常的满秩 Fisher 信息理论。原始根参数在此处可能只有 \(n^{-1/4}\) 量级，并出现非高斯极限。也不能只凭“相对目标沿该一阶零方向的导数为零”，就断言原始约束估计器的目标具有通常的中心极限定理。

下面给出绕开根分解的正则估计构造。它证明相对动态可以正则估计的存在性；不自动证明原始八个时间常数的约束非线性拟合具有相同分布或效率。

## 2. 用端到端分母系数替代不可稳定分离的根

定义每个有效通道的归一化二次多项式
\[
d_{jk}(s)=1+a_{jk}s+b_{jk}s^2,
\quad a_{jk}=t_{y,j}+t_{u,k},\quad b_{jk}=t_{y,j}t_{u,k}.
\]

直接拟合扩大后的模型
\[
G_{jk}(s)=e^{-s\ell_{jk}}\frac{P_{jk}(s)}{d_{jk}(s)},
\]
不解 \(d_{jk}\) 的两个根，也不在初始正规估计步骤强加各边系数都来自八个时间常数的非线性乘积约束。

机械矩阵保持
\[
P(s)=M/s^2+D+\sum_{i=1}^{4}\left(\frac{R_i}{s-\lambda_i}+\frac{\bar R_i}{s-\bar\lambda_i}\right),
\qquad \operatorname{rank}M=3,
\]
且没有独立自由的 \(H_1/s\) 项。

### 必须明确的条件

1. 本定理覆盖 \(0<t_{a,j}<\infty\) 的二阶端到端分母。若某路时间常数为零，模型阶次改变，需要另行按阶次分层处理。
2. 各个 \(d_{jk}\) 的根处于指定的稳定滤波区域，该区域与机械极点允许区域严格分离。滤波区域必须允许重实根附近的非实共轭根，才能把多项式系数当成内点参数；不能同时强制判别式非负。
3. 在所用通道的每个滤波根 \(p\) 上，\(P_{jk}(p)\ne0\)。这个条件排除完全或部分的滤波极点消去。
4. 非零刚体通道图连通；时延分配规范及模态因子冗余已固定。
5. 机械极点互异、非实、稳定且留数矩阵非零。矩阵参数采用光滑、无冗余局部坐标。

重复滤波本身不违反任何一项：可以同侧重复、跨侧重复，也可以所有通道均使用相同的一阶滤波。

## 3. 连续频带 Jacobian 满秩证明

设扩大模型的参数微扰使 \(\delta G\equiv0\)。逐通道消去非零公因子：
\[
\delta P_{jk}(s)=\left[s\,\delta\ell_{jk}+\frac{\delta d_{jk}(s)}{d_{jk}(s)}\right]P_{jk}(s).
\tag{1}
\]

左侧和 \(s\delta\ell_{jk}P_{jk}\) 在滤波区域解析。若 \(p\) 是 \(d_{jk}\) 的 \(m\) 重根，且 \(P_{jk}(p)\ne0\)，式 (1) 强制 \(\delta d_{jk}\) 在 \(p\) 至少具有 \(m\) 重零点。对全部根求和，得到
\[
d_{jk}\mid \delta d_{jk}.
\]

而 \(\deg\delta d_{jk}\le2\)、\(\delta d_{jk}(0)=0\)、\(d_{jk}(0)=1\)，因此
\[
\boxed{\delta d_{jk}=0.}
\]

这一步包含重根情形，完全不要求滤波根互异。

随后式 (1) 退化为
\[
\delta P_{jk}=s\delta\ell_{jk}P_{jk}.
\]
比较原点的 \(s^{-2}\) 与 \(s^{-1}\) 系数，得
\[
\delta M=0,\qquad \delta\ell_{jk}M_{jk}=0.
\]
由刚体通道图连通性，时延微扰仅剩公共跨侧分配规范；固定规范后全部为零。最后比较机械极点的二阶、一次主部及常数项，得到全部机械参数微扰为零。

所以，扩大模型在真值附近的连续频带 Jacobian 满列秩。正定权重与有正密度的频率设计给出正定局部信息矩阵。

若某个通道恒等为零，就不应给该通道附加一个不可估计的独立 \(d_{jk}\) 参数。**本文满秩联合辨识定理采用完整 4×4 数据、全部 16 个附有独立分母参数的通道均满足非消去条件。** 连通子图足以支持后面的相对动态路径重构，但不能据此声称仅用一棵树的 7 条 FRF 就可辨识完整 M、D 及任意模态留数矩阵。减少观测通道时，机械参数还需另外的空间可辨识条件。

全局唯一性也可在同一模型域内证明：每条观测 FRF 在滤波区域中的极点及其重数唯一确定该通道全部滤波根；没有消去且滤波区域与机械区域不相交，故归一化 \(d_{jk}(0)=1\) 唯一确定多项式。逐通道乘回 \(d_{jk}\) 后，回到原主文纯时延模型的全局唯一性证明。连续频带论证不直接覆盖任意有限频率格点；有限格点仍需排除时延混叠并验证有限设计的可辨识性。

## 4. 相对动态直接是正则系数的光滑函数

先取完整矩阵情形，固定参考输出 \(r\)、参考输入 \(c\)。定义
\[
H_{y,j}(s)=\frac{e^{-\tau_{y,j}s}}{1+t_{y,j}s},\qquad
H_{u,k}(s)=\frac{e^{-\tau_{u,k}s}}{1+t_{u,k}s}.
\]

无需分解任何根，便有
\[
\boxed{
\frac{H_{y,j}}{H_{y,r}}
=e^{-s(\ell_{jc}-\ell_{rc})}\frac{d_{rc}}{d_{jc}},
\qquad
\frac{H_{u,k}}{H_{u,c}}
=e^{-s(\ell_{rk}-\ell_{rc})}\frac{d_{rc}}{d_{rk}}.
}
\tag{2}
\]

所有相同滤波因子在真实模型中代数消去。即使时间常数全部相同，两式仍为良定义的光滑多项式比；没有平方根，也没有时间常数的根排序。

在无虚轴滤波根的紧频带上，式 (2) 对端到端系数及时延光滑。如果扩展模型估计量满足通常的正则条件并达到根 n 精度，则相对动态在整个紧频带上亦达到根 n 精度；有限频率集合的协方差由普通 delta 方法给出。采用合适函数空间版本，还可以得到频带函数的高斯极限。

这是完整、可构造的结论：先以正则系数估计，再进行光滑目标映射。因此不需要对奇异根参数实施不适用的普通 delta 方法。

若仅有连通子图，两个同侧节点通过偶数长度路径相连；对路径中共享对侧节点的相邻边，按式 (2) 连乘即可得到相对动态。需要事先固定路径，避免数据选择路径引入额外非光滑性。

## 5. 统计声明的准确边界

采用原主文中的观测噪声、紧参数域、导数包络、正确权重与一致极小值等条件，扩展模型可以直接采用普通加权非线性最小二乘的一致性及渐近正态理论。真值有重复滤波根，不妨碍系数坐标满足这些条件。

仍需区分：

- 本结论证明存在正则的相对动态估计程序；不声称所有原始时间常数拟合程序均正则。
- 原始物理八参数子模型可能提高统计效率，但在重根点有奇异约束。若再把初始估计投影回这个子模型，需要单独分析投影的渐近性质。
- 不允许只估计根后用通常正态区间，再将其当成重复根附近有效的置信区间。
- 频点数不自动等于独立有效样本量；实际 FRF 观测模型仍需验证。
- 时间常数相同或接近不再造成根分配的结构性障碍，但频带太窄、滤波极点过远、信噪比低仍可导致很差的条件数。

## 6. 可实现校准与对旧结论的连接

式 (2) 的逆乘上足够大的公共延迟，可以直接作为校准器。例如
\[
C_{y,j}(s)=e^{-s(T_y-\Delta\tau_{y,j})}\frac{d_{jc}(s)}{d_{rc}(s)},
\quad \Delta\tau_{y,j}=\ell_{jc}-\ell_{rc},
\quad T_y\ge\max_j\Delta\tau_{y,j}.
\]

输入侧同理。二次多项式比为 proper，分母 Hurwitz，因此动态部分稳定、因果；公共延迟使指数部分因果。精确情况下，全部输出被对齐到 \(e^{-T_ys}H_{y,r}\)，输入被对齐到 \(e^{-T_us}H_{u,c}\)。允许整体仍保留公共滤波。

统计推导中可以选择固定且充分大的 \(T_y,T_u\)，避免 max 操作在并列最大值处的非光滑性；若使用样本 max，则仅变化公共相位，对刚体幅值界影响可单独消去。

扩大模型在有限样本下不一定精确具有节点因子分解，但式 (2) 的估计函数收敛到真实相对动态，并有根 n 误差。与秩三刚体残量的根 n 估计一起，足以接回主文的双侧二阶刚体泄漏界及 \(O_p(n^{-1})\) 结构泄漏结论。

这里没有声称校准器增益必然不超过 1。若需增益限制，可以再加公共稳定低通；其柔性衰减必须计入性能证书。

## 7. 审查结论

**允许公共或重复的一阶滤波之后，校准所需的相对动态可以得到正则的数学闭环。** 关键不是证明每个时间常数的物理归属都可稳定恢复，而是用可正则估计的端到端分母系数直接表示相对动态。

核心仍依赖明确的物理模型边界、滤波—机械极点区域分离、通道非消去、连通激励及统计条件。该结论不覆盖任意未知滤波或任意极点消去。
