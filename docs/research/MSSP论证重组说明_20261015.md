# 对照 MSSP 的论证重组

本轮修改对象是根目录的 `论文初稿_相对通道动态辨识与刚柔解耦自校准.tex`。原详细大纲、论文梗概均保留；修订前初稿保存在 `history/论文初稿_MSSP论证重组前_20261015.tex`。

## 一句话主张

在含刚体双积分的多变量加性模态系统中，从完整闭环数据联合估计机械结构与相对通道动态，并将同一估计的误差联系到可实现的解耦更新和实际泄漏。

## 修订后章节职责

1. 引言：交代为什么完整端口辨识需要共同处理机械结构与相对动态。
2. 问题描述：定义一般加性模型、具体求解的模态与通道族、数据入口及待求优化问题。
3. 联合辨识：给出能计算的参数映射、预测器、数据初值、残差/Jacobian、迭代与目标提取。
4. 理论与用途：依次给出物理族唯一性、扩大系数族局部正则性、有限设计统计条件、目标灵敏度、动态对齐和分块误差界。所有证明仍在正文。
5. 数值验证：分别回答模型是否预测独立数据、相对目标是否恢复、校准是否带来收益，并保留适用范围。
6. 结论：回到辨识到解耦的单一主张。

## 主张与证据边界

| 主张 | 证据与状态 |
|---|---|
| 公共或重复滤波下相对目标唯一 | 物理通道族内的条件性定理；不是任意滤波模型的全局唯一性 |
| 系数坐标避免重复根的根分配奇异性 | 局部微分论证；不意味着有限频带的弱辨识消失 |
| 一次系数的加性约束保持原点积分结构 | 原点展开与 Schur 补证明；已有实现诊断仅作结构证据 |
| 算法的导数可以完整计算 | 结构方向导数、精确采样导数、闭环 Kronecker 链式映射；本轮新增代数核对 |
| 相对目标误差影响解耦性能 | 条件性误差界与当前合成对象上的独立验证 |
| 所设失配下动态对齐有用 | 已有 B1/B4 同一静态估计的消融；不是对其他完整辨识算法的排名 |
| 渐近正态性、实际硬件性能、普遍收敛优势 | 当前均无充分数值或硬件证据，不作已经实现的结论 |
