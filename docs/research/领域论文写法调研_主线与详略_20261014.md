# 领域论文写法调研：从详细推导稿到论文梗概

调研日期：2026-10-14。任务是学习相近领域的论证安排，不是重新扩大研究范围或承诺某期刊录用。原详细 TeX 保留；另存《论文梗概_面向刚柔解耦自校准的辨识.tex》。新梗概按方法论文写，采用“具体工程任务 → 辨识困难 → 相对结构 → 任务验证”的顺序。

## 2. 这些样本带来的写作判断

以下是针对本稿的归纳，不是期刊硬性规定。

1. **篇幅由主要主张决定。** González 的统计篇幅有对应证据；我们当前的主要证据是结构识别条件和独立校准性能，应把篇幅给它们。
2. **先建立读者的整体理解，再展开技术。** 方案总览回答输入、输出及技术难点，避免读者在多个引理后仍不知道算法做什么。
3. **方法和应用可以是一条论证链。** 我们的中心是“恢复对解耦足够的结构”；校准是这一恢复是否有用的检验，不是另起一个控制器设计项目。
4. **验证应复现问题，而不是复述算法。** 总频响拟合之外，必须展示实际泄漏、噪声和目标柔性保留；不同任务分别使用对应指标。
5. **简洁不等于省略条件或失败。** 主要假设、失败比例及独立数据边界不能隐藏；完整证明、日志和种子可以换位置。
6. **不照搬 Nature 的版式。** 本稿按工程方法论文的“引言—问题—方法—性能联系—验证—结论”组织；学习聚焦与证据对应，不追求泛化叙事。

## 3. 对现稿的诊断与处理

| 现稿的负担 | 对读者的影响 | 新梗概中的处理 |
|---|---|---|
| 工程动机、一般统计、证书、失配反例同等展开 | 读者难以判断最关键的增量 | 两条主要理论线：目标可辨识性；估计误差到解耦性能 |
| 每章都有任务说明，后面还有多轮证据审计 | 更像内部研究档案 | 内部信息保留原稿；梗概只规划读者需要的论证 |
| 早期32系数、修正23系数、失败起点穿插 | 调试历史盖过结构必要性 | 正文先提出结构保持参数化，短引理解释原因；详细失败计数移复现材料 |
| 各风险各开一条理论或实验线 | 读起来像多篇论文的集合 | 只保留影响核心结论的边界；不设计新控制器、不扩展一般摩擦或任意滤波 |
| 低频提升数字容易成为唯一亮点 | 可能被质疑把柔度当共振，或以削弱信号换泄漏下降 | 低频和共振并列；总频带RMS与逐阶保留分开 |
| 数值、未来实验、既有证明状态混排 | 证据强度不清楚 | 已有仿真与待硬件实验逐项标注，不写成已验证工程效果 |

正文内容预算为 I–VI：10%、12%、25%、18%、30%、5%，不包括参考文献。它是我们选择的编辑预算，不是任何期刊的官方限制。图表预算为5图2表；不为凑数量新增实验。

## 4. 主张与证据分开保存

| 主张 | 条件/证据 | 可能推翻或削弱它的结果 | 当前定位 |
|---|---|---|---|
| C1：相对动态和刚体子空间在给定模型条件下可恢复 | 原稿可辨识性定理、公共/重复滤波论证；需要完整数据、非消去、区域分离、支撑连通、有效有限设计 | 在相同假设内存在不同目标给出相同观测；或实际数据设计存在未处理歧义 | 条件性理论，不是任意平台保证 |
| C2：结构保持的联合估计可把上述目标转成可计算结果 | 原闭环估计程序；一次系数加性约束；稳定性/可行性与停止条件核查 | 参数化保留了非物理原点极点；大量求解失败；硬件模型失配主导 | 有限工况实现证据；换坐标优化优势尚未重跑验证 |
| C3：恢复目标能降低泄漏，同时保留可观测的目标柔性 | 分块误差界、独立闭环记录、低频及第一共振评价、逐阶投影结果 | 改善仅在模型自验证出现；噪声上升抵消收益；目标模态被抑制；真实失配过小 | 已有合成工况证据，硬件收益待测 |

统计一致性/正态性是条件性支撑。若实际优化未满足精度门槛，不把定理等同于求解器已得到相应分布；当前不主张置信覆盖已验证。相对响应的信息可以较强，而单独物理时延和时间常数仍弱，这两点不矛盾。

## 6. 审稿人最可能的三个疑问

- **“已有动态解耦，新的辨识贡献在哪？”** 用C1的具体目标/歧义/条件，以及C3的性能联系回答；最接近文献表不写未读全文的排他性结论。
- **“只看拟合或零空间内自检，能证明实际改善吗？”** 给独立验证记录，分离训练与选解；硬件需要独立参考或专门验证协议，不用同一模型制造真值。
- **“时延不准，为什么校准仍好？”** 评估整体相对动态与子空间，并解释物理参数弱方向；不把换尺度当作增加信息或通过统计门槛的证据。

## 7. 统一术语

| 统一用语 | 含义/写作约定 |
|---|---|
| 相对通道动态 | 同侧通道相对参考通道的复频响，包含相对时延和滤波差异 |
| 有效刚体子空间 | 由M恢复的输入/输出子空间；不等同于完整几何参数或指定物理轴 |
| 刚柔解耦自校准 | 由完整数据辨识结果更新动态对齐与零空间；不暗示在线反复采集 |
| 普通刚体串扰 / 双侧柔性残差 | 分别使用一阶 / 特定二阶误差界，不混用 |
| 结构保持的系数参数化 | 端到端分母系数，保留一次系数加性结构；不承诺普遍精度优势 |
| 数字参考 | 真参数与相同数字实现的对照，不称绝对最优或所有指标的下界 |
