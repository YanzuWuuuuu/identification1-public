# 模型约定：四个目标模态与常数直通项 D

日期：2026-10-13。按本轮讨论更新论文的模型约定；未修改 MATLAB 算法或原始数据。

## 1. 主模型

论文拟合模型采用

\[
\widehat G(s)=e^{-s\tau}
\left[
\frac{M}{s^2}
+\sum_{i=1}^{4}\frac{B_{i0}+B_{i1}s}{A_i(s)}
+D
\right],\qquad
A_i(s)=1+a_{i1}s+a_{i2}s^2.
\]

实模态情形令 \(B_{i1}=0\)，并在结构估计阶段施加适当留数约束。引入 D 不自动改变原先的阻尼参数化。

\(D\in\mathbb R^{4\times4}\) 是在拟合频带内不随频率变化的矩阵，用来表示未显式保留高阶模态的静态残余贡献。不额外增加极点或模态数，一般不施加单模态秩一约束。

假定时延来自全系统共享的输入/测量通道，所以 D 与其他项一起乘 \(e^{-s\tau}\)。若另有绕过该时延的直接串扰通道，才需要 \(e^{-s\tau}P(s)+D_{\mathrm{bypass}}\) 的另一种模型；本轮不引入这种路径。

论文中更准确的名称为“高阶残余的常数近似”或“残余柔度项”。D 一旦进入拟合模型，其所表示的常数部分已经被建模，剩余频率相关误差才属于模型失配。

该形式与参考论文 Section 6.2 中用额外 DC gain 表示高阶动态的做法一致；原文还说明该项可为满秩。因此“增加 D”本身不作为创新。[原文](https://arxiv.org/html/2510.10820v1)

## 2. 当前理论范围与暂缓事项

按最新讨论，当前理论真实系统采用“四模态＋常数 \(D^*\)＋共同时延”，在正确模型假设下研究时延信息，并分别检查可辨识性、求解器及正则性条件。

四、五阶接近的截断近似误差验证暂不展开，需要时再加；本轮不以第五阶动态替代 D，也不根据第五阶计算 D。现有第五阶对象保留不动，但不进入本轮主推导与数值核查。以后若启用该验证，须将 \(G_5(s)-D\) 作为模型失配单独评价。

## 3. D 的估计不必增加外层非线性搜索

在 \(\tau\)、分母和其余系数给定时，D 是实线性参数。记

\[
r_k=\operatorname{vec}\left(e^{s_k\tau}G_k-P_0(s_k)\right),\qquad
d=\operatorname{vec}D,
\]

其中 \(P_0\) 不含 D，频点目标权重为 Hermitian 正定 \(W_k\)，则

\[
\widehat d=
\left(\sum_k\operatorname{Re}W_k\right)^{-1}
\operatorname{Re}\left(\sum_kW_kr_k\right).
\]

实际数值求解使用线性方程，不显式求逆。所有分子、刚体残量及 D 也可在给定极点和时延后联合线性求解；存在模态秩约束时需用相应结构参数化。

在加性 RIV 框架里，D 对应固定分母为 1 的块；时延补偿后的有理模型对 d 的导数为单位矩阵，完整延迟模型的导数为 \(e^{-s\tau}I\)。上一轮固定点与驻点的代数关系可以相应扩展，仍不因此获得全局最优保证。

## 4. 时延信息结论要随 D 更新

共同延迟模型的 D 导数是 \(J_D=e^{-s\tau}I\)，时延导数新增 \(-s e^{-s\tau}D\)。

重新推导得到更强的结论：若 B0、B1 与 D 均自由估计，任意真实 B1 下都有

\[
-s\frac{B_0+sB_1}{A(s)}
=-\frac{B_1}{a_2}
+\frac{B_1/a_2+s(a_1B_1/a_2-B_0)}{A(s)}.
\]

因此柔性部分的时延导数被分子参数与 D 的允许方向精确吸收，不再要求真实 \(B_{i1}^*=0\)。有效信息为

\[
I_{\tau\mid\theta}
=2\left\|
(I-\Pi_\theta)e^{-s\tau}
\left(-\frac{M}{s}-sD\right)
\right\|_{C^{-1}}^2,
\]

此处按全部频点和通道堆叠，\(\Pi_\theta\) 包含 D 及其余允许参数的实切空间投影。C 为已知、参数无关的 proper 复高斯噪声协方差。常数分子模型不允许 B1 变化，须使用完整 Jacobian，不能照搬此化简。

这修正了无 D 情况下“剩余信息只来自刚体投影残差”的结论：

- 当真实 D 为零，只是允许估计 D 时，新增 nuisance 参数不会凭空创造时延信息；完全去掉刚体后，自由一次分子的原零信息结论仍成立。
- 当真实 D 非零，\(-sD\) 是新增的时延敏感方向，可能在去掉刚体后仍留下信息，需要结合实际约束和频点检验。
- 比较“同一个真实系统的 D 已知／未知”时，放开 D 的估计只会保持或降低有效信息；比较 D=0 和 D≠0 则是改变真实系统，两者不能混为一谈。
- 刚体与 D 的投影后方向存在交叉项，不能将二者的信息直接相加；D 增大也不保证有效信息单调增加。
- 若 D 仅是近似项，由该模型计算的信息量不能替代对实际动态残差造成的偏差检查。

原先无 D 的 0.536、0.980、0.198 等数值不直接作为新模型的结论。完整证明与四模态重新计算结果见同目录《时延信息重推导_四模态与常数D.md》。本轮已完成确定性 Jacobian 与信息投影核查，未运行新的辨识或 Monte Carlo 实验。

## 5. 论文主线的表述更新

当前聚焦为：**冗余柔性运动平台中，带常数残余补偿的时延与目标模态联合辨识。**

核心问题仍是物理结构、时延信息和模态参数之间的混淆。D 是建模组成部分；当前优先验证正确常数背景下，冗余通道和频带的保留如何影响时延及模态辨识。动态截断近似误差在有需要时另加。尚未运行含 D 的新辨识实验，不沿用无 D 结果宣称改进。
