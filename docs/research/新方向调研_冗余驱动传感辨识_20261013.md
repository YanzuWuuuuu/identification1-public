# 冗余驱动与冗余传感能为辨识增加什么：新方向核查

日期：2026-10-13（Asia/Tokyo）。范围：本项目 4 输入、4 输出、3 个刚体自由度、4 个目标柔性模态与常数直通项 D。不读取用户撤回的 Word。本文是独立研究判断与候选方案，不是已经完成实验的论文结果。

## 1. 建议结论

**优先研究“通道动态的相对校准与机械模态分离”，把 SRIVC 降为可替换的估计器。** 用户已说明各通道共用时钟，但滤波或滞后可能不同。因此主问题应当是：执行器链和测量链的动态不一致，如何与真正的柔性模态、一般阻尼和刚柔解耦误差区分。不能继续把所有相位误差解释为一个公共纯时延，更不能写成无线传感器时钟同步。

双侧冗余在这个问题里有明确作用：当刚体内部传递函数完全未知时，已知的刚体输入、输出几何子空间为两侧通道相对传递函数提供约束。刚体自由度等于输入、输出数且内部传递函数完全自由时，该约束消失。这是可辨识性层面的作用，不是“多通道取平均”。

但应保持克制：已知子空间下的盲增益/相位校准已有成熟理论，不能把几行零空间比值公式命名为新算法。潜在论文增量必须落到 **柔性和 D 污染下的双侧校准边界、有限频带偏差与方差、通道动态和机械动态的分离条件，以及独立校准实验**。

第二候选为“任务闭环中的最小附加激励与完整物理输入方向辨识”。该路线实现容易，现有代码也有基础，但零空间激励、Fisher 信息优化、执行器参数辨识已经有直接先例。仅证明三维任务参考不足、加一维 null 参考补秩，通常不够支撑新方法论文。它更适合作为第一候选的实验获取环节。

## 2. 项目背景核查与不可忽略的限制

已读 `matlab/0/Multiple_main_Control.m`、既有几何核查与文献报告。仿真植物为

\[
P(s)=C_r\operatorname{diag}(J_x^{-1},J_y^{-1},m^{-1})B_r/s^2+P_f(s),
\]

其中 \(B_r\in\mathbb R^{3\times4}\)、\(C_r\in\mathbb R^{4\times3}\) 均秩 3，刚体留数 \(M\) 秩 3。各侧只有一维零空间。原脚本包含 5 个柔性模态，而当前论文约定只估计前 4 个并用常数 D 描述带外背景；第 5 阶近邻截断测试暂不纳入主问题。

已有核查得到右、左几何零向量（单位范数，符号约定末分量为正）：

\[
n_u\simeq[-0.27219,-0.26738,-0.39102,0.83757]^T,
\quad n_y\simeq[-0.56447,0.56418,-0.42464,0.42749]^T.
\]

所有分量非零，适合下面的相对校准条件。对模态辨识则不一定有利：第一模态在输入 null 方向参与度仅约 0.036，第二模态在输出 null 方向参与度仅约 0.022。**不能只保留一个 null-null 标量响应识别所有模态，更不能由它恢复任意完整左右振型。**

本地脚本确实生成四路独立外部输入噪声，但已有保存数据是否保留对应外参考、实际电流/力、滤波前后量和校准设置，需要另行核对。当前没有检索到可独立核实的真实平台通道动态校准记录；仿真矩阵不能当成实物精确几何。

另外，4×4 不意味着 FRF 对称。当前 B、C 不是同一组物理自由度上的互易测量矩阵；没有互为功共轭且共置的输入输出定义，不能强制 \(P=P^T\)。

## 4. 候选一：双侧通道动态相对校准，然后辨识机械系统

### 4.1 研究问题与模型

使用

\[
G_m(s)=Q_y(s)\left[C_rH_r(s)B_r+P_f(s)+D\right]Q_u(s),
\]

其中 \(Q_y,Q_u\) 为可逆对角通道动态，包含已知/未知滤波和可能的纯时延；\(P_f\) 是目标柔性模态。机械背景、通道动态与闭环控制器必须区分。系统输入若记录的是滤波后实际力，则对应上游滤波不再属于这个输入到输出的植物；若只记录滤波前命令，则它必须进入 \(Q_u\)。

最有价值的实际问题是：仅按机械模型拟合时，通道相位不一致可能被当成一般阻尼、复杂振型或额外模态；名义静态 null 也不再消去刚体，导致后续模型和分配错误。应测量这些后果，而不只报告总 FRF 拟合率。

### 4.2 刚体主导的理想命题：双侧相对传递函数可恢复

先令 \(P_f+D=0\)，固定一个非奇异频率，写

\[
Z=Q_y C_r H B_r Q_u,
\quad \operatorname{rank}H=3.
\]

已知 \(C_r^Tn_y=0\)、\(B_rn_u=0\)。设观测得到左零协向量 \(\ell^T Z=0\) 与右零向量 \(Zr=0\)。因为中间各映射在三维子空间满秩，存在非零标量 \(a,b\)，使

\[
\ell^T=a n_y^T Q_y^{-1},\qquad r=bQ_u^{-1}n_u.
\]

对任意参考通道 0，当相关几何分量非零时，

\[
\frac{q_{y,j}}{q_{y,0}}
=\frac{n_{y,j}\ell_0}{n_{y,0}\ell_j},
\qquad
\frac{q_{u,k}}{q_{u,0}}
=\frac{n_{u,k}r_0}{n_{u,0}r_k}.
\]

这两个比值不依赖未知 H，且零向量任意幅相归一化自动约去。若左零向量来自复 SVD 的列 \(l\)，实现应使用 \(\ell^T=l^H\)；不能把共轭误删。

**歧义：** 该信息只能确定各侧相对动态。任意公共标量函数 \(h_y(s),h_u(s)\) 可分别乘到 \(Q_y,Q_u\)，再由 H 吸收。两侧各有一个公共函数自由度；仅靠子空间关系无法确定其绝对幅值、公共滤波或公共时延。可通过选定基准通道得到规范化表达，但把基准设为 1 是坐标约定，不是证明它没有动态。

**冗余的必要作用：** 若 \(C_r,B_r\) 都是可逆方阵且 H 完全未知，任意可逆 \(Q_y,Q_u\) 都可吸收到新的 H，因而没有上述校准信息。这里多于刚体自由度的输出提供一个左一致性约束，多于刚体自由度的输入提供一个右一致性约束。

**此命题在数学上是子空间盲校准的直接特例，不能未经排重称为新定理。** 当前 4 对 3 且零向量所有分量非零，是该特例最简单、也最容易给出闭式表达的情形。

### 4.3 柔性和 D 存在时，什么仍然成立

对自由刚体理想项 \(C_rH_rB_r=M/s^2\)，若柔性和 D 在 0 附近解析有界，且通道动态在 0 附近解析可逆，则

\[
s^2G_m(s)=Q_y(s)\{M+s^2[P_f(s)+D]\}Q_u(s).
\]

刚体矩阵为秩 3，第四奇异值由柔性、通道误差和噪声产生。将其最小奇异向量代入上式不再精确，偏差受柔性项及第三奇异值间隙控制。若通道幅值/逆幅值有界且刚体非零奇异值有统一正下界，标准奇异子空间扰动论给出随频率趋零的 \(O(\omega^2)\) 子空间误差。比值校准的误差还需要几何零向量分量及观测分量不接近 0。

可以进一步推导的有效结果是：给出这个界的显式常数，并将其传播到校准后的机械 FRF、模态留数和阻尼误差。**不能把 Wedin/Davis–Kahan 扰动原理本身列为创新。** 也不能仅凭观测到第四奇异值很小，就证明所有柔性污染很小：落在原刚体行列空间里的污染可能不增加第四奇异值。

若 DC 增益已归一化，

\[
Q_y(s)=I-sK_y+O(s^2),\quad Q_u(s)=I-sK_u+O(s^2),
\]

则

\[
\left.\frac{d}{ds}(s^2G_m)\right|_{s=0}=-K_yM-MK_u.
\]

柔性与常数 D 不进入这一阶项。因此可估计相对一阶群滞后，再由明确的通道模型处理高频。然而 \(e^{-s\tau}\) 与 \((1+sT)^{-1}\) 的一阶项分别为 \(-s\tau\)、\(-sT\)，低频一阶证据无法区分它们。要说“辨识出纯时延”，必须有已知滤波结构、足够宽带的幅相数据或独立标定。

### 4.4 必须保留的反证：理想刚体已知形式时，冗余并非唯一信息来源

如果严格采用 \(M/s^2\) 且完整 FRF 可用，对所有非零 \(M_{ij}\)，

\[
-\frac{[s^2G_m]'_{ij}(0)}{M_{ij}}=\kappa_{y,i}+\kappa_{u,j}.
\]

非零 M 元素组成连通二部图时，各侧一阶滞后可恢复到一个输入/输出分配自由度；这不要求 M 秩亏。因而不能用这条斜率等式证明“只有冗余平台才能辨识时延”。

几何方法更具体的优点是消去对 H 的依赖。例如允许 \(s^2C_rH_r(s)B_r=M+sC_rH_1B_r+O(s^2)\) 时，左右 null 消去未知 \(C_rH_1B_r\)，仍约束各侧相对一阶滞后，但公共滞后不再可由该证据分离。引入 H1 必须对应真实结构内的模型不确定性，不能为了显得有创新而凭空增加它。

### 4.5 算法候选：估计器可替换，物理约束必须保留

1. 以独立外部参考获得闭环有效 FRF/跨谱及协方差，或直接做满足相同矩条件的多实验估计。
2. 在刚体主导且信噪比足够的频带，联合估计左右子空间及相对通道参数。优先用加权结构残差拟合，而不是直接相除弱奇异向量。
3. 用不同低频上限、不同多项式阶次/已知滤波结构评估偏差；保留独立频率或重复试验检验外推。
4. 将已知或估计相对动态去嵌入，传播标定不确定度。非最小相位通道离线频域校正可做，但不能自动变成稳定因果在线逆补偿器。
5. 用全通道数据估计机械四模态和 D。可用频域子空间/Loewner/vector fitting 获初值，再做结构化加权输出误差或合适 IV；不必将 SRIVC 放在标题。
6. 检查模型是否把通道极点当成机械模态。单个传感通道极点常在一行出现、单个驱动通道极点常在一列出现，可提供诊断，但节点、极点重合和多路共用滤波会破坏这种简单判别，不能单独作为保证。

### 4.6 必须证明/验证的内容

- **可辨识边界：** 两侧相对动态、公共动态和物理模态之间的等价变换；明确哪些已知量消除哪些自由度。
- **污染界：** 柔性与 D、几何误差、频带和奇异值间隙对相对校准的影响；低频纯延迟与群滞后区别。
- **统计和闭环条件：** 若拟合相对比值，分母噪声引起偏差；尽量在原始矩阵数据层加权。使用正确参考与协方差，不能因共享时钟而假定输入外生。
- **机械解释保真：** 校准前后同一模态的频率、阻尼、复留数，以及刚柔解耦泄漏；独立测量链校准提供对照真值。

### 4.7 强基线与否决条件

强基线至少包括：

| 基线 | 为什么必要 |
|---|---|
| 独立已校准测量/驱动链 + 全数据结构化联合估计 | 验证辨识出来的是物理机械量，提供可达到的精度参考。 |
| 2026 结构模态辨识，同样输入噪声模型和参数阶数 | 检查现有复模态模型是否已经足以预测，量化其物理解读误差。 |
| 全数据联合估计机械模型与同样的对角通道模型，充分多初值 | 防止仅以较差初始化制造优势；新方法应在可辨识诊断、稳定收敛或标定代价上有收益。 |
| 通用子空间盲增益/相位校准，再做同一机械估计 | 检查机械专用理论与污染处理是否超出通用方法的直接应用。 |
| 仅左冗余、仅右冗余和双侧冗余 | 分清两侧分别提供何种约束，不能只比较通道数。 |

失败条件：所有通道动态实际一致；可用频带内不存在刚体主导区；关键几何零向量分量很小；闭环输入秩不足；几何失配与通道动态无法区分；通道函数完全任意且没有足够锚点；补偿后仅改善总拟合而不能改善独立校准、模态或解耦指标。出现这些情况，应收缩为诊断工具，不强行声称完整机械模型可盲分离。

## 5. 候选二：闭环任务参考不足时的最小附加激励

### 5.1 冗余带来的是可控的额外实验方向

设常规分配 \(T_b=B_r^\dagger\)，控制输入为

\[
u=T_bK(r-T_yy)+n_u\nu.
\]

只有三维独立任务参考 r 时，逐频 \(S_{Ur}\) 至多秩 3，无法唯一恢复无约束四输入 FRF。加入独立 \(\nu\) 后，\(\xi=[r^T,\nu]^T\)，在闭环稳定、相关矩阵可逆且 K 在选定频率满秩时，

\[
S_{U\xi}=(I+T_bKT_yG)^{-1}[T_bK\ \ n_u]S_{\xi\xi}
\]

可满秩 4。再用 \(S_{Y\xi}=GS_{U\xi}\) 估计开环植物或构造 IV。外参考独立于噪声是关键；记录下来的 u 因反馈通常并不外生。

这条秩结论是标准闭环辨识与线性代数，不是独立新贡献。若模型有强有限维结构，逐频参考秩不足并不自动意味着所有参数都不可辨识；应同时检查整个参数 Jacobian，而不能把非参数秩条件扩大为任意参数估计的必要条件。

输入 null 满足名义 \(B_rn_u=0\)，提供小刚体广义力的附加实验方向；输出 null 满足 \(n_y^TC_r=0\)，提供对刚体子空间内响应的消除约束。两者作用不同。刚体零力不等于闭环运动完全不变，未知驱动滤波 \(Q_u\) 也会使 \(B_rQ_un_u\ne0\)。

### 5.2 若要成论文，需要比“补秩”多什么

可能的具体问题是：**在通道动态不确定和任务运动约束下，为目标柔性模态选择最小附加激励，使完整物理留数达到可辨识而不造成不可接受的运动。** 可将候选一的相对动态用于更新频率相关 null 方向，先标定再设计激励，并分析标定误差导致的刚体泄漏。

但这不是零空间激励的概念创新。必须与 2020 MIMO 元素约束 OED、2023 null-space adaptive identification 和同预算四路独立激励比较。单独写“信息矩阵秩从 3 到 4”或“null 激励增大 Fisher 信息”不足。

值得证明的增量可能是：通道不确定性下泄漏上界与目标模态信息的联合可行条件；哪些目标模态在现有一维 null 中不可观测、必须由任务参考补足；可靠停止/拒绝辨识的标准。不能承诺固定 4 对 3 几何可通过旋转 null 方向任意改善弱模态，因为该 null 只有一维。

推荐地位：作为候选一的实验设计环节；只有存在必须边运行边辨识的真实场景和严格运动预算时，才考虑独立成篇。

## 6. 为什么不优先换成其他热门估计器

| 方法 | 可以怎样用 | 为什么不能直接成为创新 |
|---|---|---|
| 频域子空间 / N4SID | 获得共享状态空间极点初值；后续施加机械结构。 | 结构化物理模型、互易性等投影已有；它不会自动区分通道滤波和机械模态。 |
| Loewner / tangential interpolation | 非迭代有理初值；可选择反映几何的输入/输出方向。 | 2023–2025 已有机械和 MIMO 模态应用；噪声加权与有限数据稳定性仍需处理。 |
| Vector fitting | 多通道共享极点与 D 的稳健工程初值；时延/滤波可外层处理。 | 换求解器不创造物理可辨识性；只有对象约束和实验信息变化才形成实质增量。 |
| 互易性 / port-Hamiltonian | 输入输出功共轭且物理条件满足时提供约束。 | 当前非共置四输入四输出不保证对称或被动端口表示，不能先强制再解释。 |
| DMDc / time-delay embedding | 大规模时空测量时可压缩表示。 | 当前仅四输出，无明显维度瓶颈；时间嵌入不等于辨识未知通道传输时延。 |
| 神经网络时延辨识 | 可在数据充分、在线速度必要时做对比。 | 用户要发挥双侧冗余和可解释理论；现阶段引入训练分布问题会扩大而非解决核心问题。 |

## 7. 最小判别研究包

1. 明确每个实际输入、输出记录点位于哪些滤波器之前/之后，列出已知滤波、可变滤波与真实力/位置测量能力。共用时钟不排除各路动态差异。
2. 在当前 4×4 几何上先加已知、不同的一阶滤波，不加新柔性阶次，验证相对校准、公共函数歧义及低频界。纯时延另设组，检验只用低频斜率无法区分二者。
3. 扫低频上限、通道噪声、几何角度误差和刚体非零奇异值，比较偏差—方差；不能仅报告一个噪声水平下的好例子。
4. 同一校准后数据分别交给结构 WNLS、RIV 和一个子空间/Loewner 初值方案，检验收益是否来自信息结构而非换了优化器。
5. 用独立校准或已知数字滤波插入实验验证通道动态；已知插入滤波仅证明相对变化辨识，不自动给出未插入系统的绝对真值。
6. 在 held-out 参考/任务轨迹上测刚体泄漏、柔性振型和阻尼可重复性，决定是否值得扩大实物实验。

**继续门槛：** 发现真实通道差异，并能在不完全知道机械模态时恢复相对通道动态；在合理几何误差下稳定；校准之后独立机械/解耦指标得到改善；与通用盲校准和全数据联合估计有清晰差异。

**停止或收缩门槛：** 理论只剩已知 BGPC 的直接机械改写，实物通道差异不可测，或收益只来自给对照错误模型/较差初始化。此时保留为工程校准模块，不宣称已形成足够创新的论文。

## 8. 检索边界与诚实结论

本次检索覆盖 2022–2026 的 overactuated/oversensed identification、rigid-body nullspace、actuator bandwidth identification、MIMO Loewner、sensor/actuator dynamic calibration、modal synchronization、blind gain phase calibration，并补查必要近邻旧文献。未检索到与“已知刚体双侧几何、未知两侧通道动态、柔性和 D 污染、相对校准后机械辨识”完全同一组条件的直接论文，**这仅支持进一步排重和验证，不证明首次提出**。

相对上轮“公共时延有效信息”主线，新候选的优势在于它针对用户真实给出的通道滤波差异，并且可以明确指出双侧冗余何时改变可辨识性。其风险也很清楚：不能从低频群滞后跳到任意全频通道动态，不能从相对校准跳到绝对机械分离，更不能将已有的子空间校准包装成新统计理论。
