# 不经过 LRM 的原始数据辨识试验

目的：检查能否跳过非参数 FRF 估计，直接由原始 `u1..u4`、`y1..y4` 估计四阶模态。第五阶继续作为未建模动态。

在 `matlab` 目录运行：

```matlab
result = run_raw_identification(true);
```

这会运行直接时域辨识、带模态秩约束的时域辨识、固定频段加权变体及采样保持方式对照，并在同一训练段重新拟合 LRM 参考方法。全部新结果写入 `results_raw`。原来的 0～4 入口、原始记录和 LRM 结果不被该入口覆盖。

完全不运行或读取 LRM 的版本：

```matlab
result = run_raw_identification(true, false);
```

依赖 MATLAB、Control System Toolbox 和 Optimization Toolbox。

## 算法

连续时间参数模型为：

`G(s) = M/s^2 + sum(R_k/(s^2 + 2*zeta_k*omega_k*s + omega_k^2))`。

使用原始输入经过各参数化模态滤波器得到输出预测，直接最小化原始输出和预测输出的差。输入采样间采用一阶保持（FOH），另用零阶保持（ZOH）作敏感性对照。模型包含初始位移、速度和衰减振荡的瞬态项，避免把记录起点的未知状态强迫解释成模态参数。

- `raw_time`：直接时域输出误差；对固定频率/阻尼，线性求解各通道残差矩阵和初始条件，再优化频率/阻尼。既不计算 FRF，也不在拟合目标中使用 FFT。
- `raw_time_structured`：保持上述直接时域目标，施加刚体矩阵秩 3、柔性残差矩阵秩 1。刚体输入子空间由原始数据初始拟合的 SVD 固定，柔性输入方向、频率和阻尼继续优化。
- `raw_band` / `raw_band_structured`：额外对输出预测残差使用固定 Hann 窗及 0～720 Hz 的频段权重。FFT 只计算参数模型的残差目标；没有估计非参数 FRF，没有逐通道计算 `Y/U`，也没有使用 LRM 结果作为初值。保留 DC 是为了使初始位移/速度可辨识。
- `raw_zoh`：直接时域目标的 ZOH 输入保持对照。
- `lrm_reference`：把旧 LRM 主流程在相同训练段上重新执行，仅作参考。计算全部在内存完成。

两个有结构的模型均只有四阶柔性模态。加性初始化暂时允许一般残差矩阵，其本身不是最终的秩一模态结构。

## 训练和验证

20,000 个样本，采样率 5,000 Hz。前 14,000 点（2.8 秒）训练；后 6,000 点（1.2 秒）验证。所有模型最后仅使用训练段输出校准初始条件，随后连续自由仿真，不用验证段输出更新状态、模型或参数。

沿用已有频率先验 `[286,347.5,487.5,700] Hz`，边界为先验 ±10%，上界封顶 720 Hz。阻尼限制为 0.001～0.15。因此这是有先验的四阶参数辨识试验，不是未知阶次的全频盲辨识。

验证段的频带误差用固定 Hann 窗后复数 FFT 残差的能量比计算。这里的指标是原始输出预测误差，不是之前的 16 通道 FRF 相对误差，不能直接与旧报告数字混用。

LRM 的原拟合频段从 5 Hz 开始；纯时域拟合还会优化接近 DC 的漂移。含双积分刚体的长时自由仿真对刚体矩阵小误差很敏感，因此同时报告全时域和分频段指标，不能凭一个总误差判定模态参数是否准确。
