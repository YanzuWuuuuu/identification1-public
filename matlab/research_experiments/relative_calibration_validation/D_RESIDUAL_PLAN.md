# D 对未建模高阶模态的补充验证

日期：2026-10-14。用户纠正：原始 `matlab/0` 最多五阶，未计算更高阶；其真值不应被无条件加上 D。本次采用 analysis-campaign 的小规模证据路线，回答“新增实际高阶动态后，五阶辨识器中的常数 D 是否改善近似”。

## 锁定的设计

- 父结论：先前真值直接添加 D=1e-8I 仅验证了含 D 正确模型，不能证明 D 可以代替实际未建模动态。本次原五阶保留不动，真实常数 D 始终为零。
- 基准：原五阶；另外三个场景各增加三个合成模态，频率为 near=[950,1200,1500]、mid=[1600,2000,2500]、far=[3200,4000,5000] Hz，阻尼均0.01。这些是假设扩展，不声称来自有限元或真实第六至八阶。
- 三个附加模态分子为固定种子生成的实秩一矩阵，其 Frobenius 范数各等于原五个分子范数的中位数。三个频率配置使用完全相同的分子，保留其符号和空间方向。频率越高会同时变平坦、变弱；分别报告尾项强度和相对于尾项本身的逼近误差，不把两者混为单一距离效果。
- 保留前次不同通道的一阶低通/纯时延，作为合成通道扰动；其真值只用于数据生成和评价。主机械对象仍为 0 的原五阶。
- 训练网格沿用固定低频70点+200:2:800Hz；使用独立验证网格。N=8独立复频响重复记录，level=.003，两个固定噪声种子。每个场景共比较同数据、同权重、同数据起点的五阶 D=0 与五阶 D自由，共16次拟合。
- 为隔离 D，本次主辨识器固定为扩大系数参数化，不再把两种动态参数化同时作为变量。D=0 用删除16自由变量实现；D自由多16变量，须如实报告这个复杂度差异。
- 起点均由相同数据初始化，仅按 D有无设其初始值。预算400次，每次记录退出状态、活动边界、Jacobian方向检查。原拟合器和旧输出不改。

## 指标与停止条件

1. 无估计误差的确定性近似：真实高阶尾项 H_h、D0=sum(A_h/omega_h^2)、H_h-D0 的幅值/L2误差、尾项对目标五阶柔性的比例；另计算该频带实常数最佳逼近 D_LS。D_LS只用于诊断，不提供给辨识器。
2. 配对拟合：加权训练残差、独立验证频带FRF误差、原五阶频率/阻尼偏差、相对通道动态误差、真实刚体/目标五阶柔性比及逐阶目标留数保留。
3. D=0原五阶基准用于辨别增加自由D是否只是在拟合噪声。训练残差更低本身不算精度更高。
4. 16次完成并确认机制后停止；不为得到正结果继续调高阶方向或强度。若程序失败，保存失败记录，先纠正实现问题；优化预算终止不被隐藏。
